# リファレンスボード

[候補一覧・検討状況](index.md)

## 一言コンセプト

集めた画像をひとつのボードに自由に配置し、全体と細部を行き来して比較しながら、制作で試したい表現や構成を見つけ、グループとコメントで着想を整理するPC向けツール。

## 着想の背景と根拠

- ユーザーの意向：PCでリファレンス画像を管理し、一覧を眺めることで新たな着想を得たい。手持ち画像やブラウザから手軽に画像を追加したい。用途は限定しない。
- ユーザー自身の課題：画像を集めて眺める際、一度に見渡せる画像が少ないことを解消したい。
- ユーザーの優先順位：最優先は「大量の画像を見渡す快適さ」。画面内に一度に多くの画像が見え、縮小して全体を眺め、気になるまとまりを拡大して比較できる体験を重視する。
- ユーザーの期待成果：参考画像の比較から、自分自身の制作で試したい表現や構成を見つけたい。実際の制作への効果は未検証。
- AIの提案・仮説：複数画像を同時に眺めることが、画像間の共通点や意外な組み合わせの発見につながる可能性がある。自由配置やグループへのコメントが、着想を整理する助けになる可能性がある。いずれも未検証。
- 外部情報：外部調査は未実施。市場・競合・需要について確認済みの事実はない。

## 想定利用者と利用場面

- 想定利用者：最初の利用者はユーザー自身。自分にとって役立つことを候補選定の判断基準とする。特定の職種や制作分野には限定しない。他の利用者にも役立つかは未確認。
- 利用場面：手持ち画像やブラウザで見つけた画像を、ドラッグ＆ドロップやクリップボードからの貼り付けで単一ボードへ直接追加し、数百枚程度を継続して蓄積する。自分で配置・グループ化する時間も楽しみながら、縮小して全体を眺め、気になるまとまりを拡大して比較し、グループに文章コメントを残す。これは確認した希望に基づく想定場面であり、利用実績や需要の実証ではない。
- 提供したい価値：一度に多くの画像を見渡し、全体と細部を行き来して比較することで、制作で試したい表現や構成を見つけられること。着想の発見や整理への効果は未確認。

## 解決の方向性と魅力

### ユーザーが選択した構想上の方向性

- PC向けとし、画像収集の用途は限定しない。OSを限定せず使いたい意向があり、画像と配置は端末内に保存したい。対応OSの具体的な範囲や提供形態は未決。
- ボードはひとつ。数百枚程度の画像を同じボードへ継続して蓄積する。「数百枚」は利用規模の目安であり、上限や性能保証ではない。
- 手持ち画像・ブラウザから、そのボードへ直接追加する。ドラッグ＆ドロップと、クリップボードからの貼り付けの両方を希望する。
- 縮小して全体を眺め、気になるまとまりを拡大して比較する。
- 最初から自分で自由に配置する。自動整列してから動かす方式より、この方向を選択した。自由配置やグループ分けは、楽しみながら考える作業として手間をかけたい。
- 画像をグループ化し、グループに文章コメントを付ける。
- 画像の特定部分を指す注釈や矢印等は不要という意向。
- 別途画像ライブラリを用意する方式や、複数ボードは今回選択されなかった。

これらは対話で確認した構想上の意向であり、確定した要求・仕様ではない。自動整列機能そのものを将来にわたり禁止するという意向は確認していない。

### 魅力と価値仮説

- 本人の関心：画像収集に加え、配置やグループ分けの過程も楽しみながら、集めた画像の比較から制作で試したい方向性を見つける体験。
- AIの価値仮説：自由配置によって画像同士の関係を自分なりに表し、グループと文章コメントによって気づきを整理できる可能性がある。
- AIの価値仮説：一画面に多くの画像が見えることで、複数のリファレンスを比較したり、組み合わせを発見したりしやすくなる可能性がある。
- 独自性・試しやすさ：未評価。競合に対する優位性や実現性を確認済みとは扱わない。
- 他の候補との関係：現時点で独立した別案は記録していない。対話中に提示した体験仮説は、ユーザーが選択した機能とは扱わない。
