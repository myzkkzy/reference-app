# リファレンスボード

[候補一覧・検討状況](index.md)

## 一言コンセプト

集めた画像をひとつのボードに自由に配置し、多くの画像を見渡しながら、グループとコメントで着想を整理するPC向けツール。

## 着想の背景と根拠

- ユーザーの意向：PCでリファレンス画像を管理し、一覧を眺めることで新たな着想を得たい。手持ち画像やブラウザから手軽に画像を追加したい。用途は限定しない。
- ユーザーの優先順位：最優先は「大量の画像を見渡す快適さ」。その意味は「画面内に一度に多くの画像が見える」こと。
- AIの提案・仮説：複数画像を同時に眺めることが、画像間の共通点や意外な組み合わせの発見につながる可能性がある。自由配置やグループへのコメントが、着想を整理する助けになる可能性がある。いずれも未検証。
- 外部情報：外部調査は未実施。市場・競合・需要について確認済みの事実はない。

## 想定利用者と利用場面

- 想定利用者：PCで画像を集め、眺めながら着想を得たい人という仮説。特定の職種や制作分野には限定しない。具体的な利用者像は未確認。
- 利用場面：手持ち画像やブラウザで見つけた画像を単一ボードへ直接追加し、自分で配置・グループ化して眺め、グループに文章コメントを残す。これはユーザーの希望をもとにした想定場面であり、実際の利用実績や顧客の発言による需要の証拠ではない。
- 提供したい価値：画面内に一度に多くの画像が見えることと、画像を眺めて新たな着想を得られること。着想の発見や整理への効果は未確認。

## 解決の方向性と魅力

### ユーザーが選択した構想上の方向性

- PC向けとし、画像収集の用途は限定しない。
- ボードはひとつ。手持ち画像・ブラウザから、そのボードへ直接追加する。
- 最初から自分で自由に配置する。自動整列してから動かす方式より、この方向を選択した。
- 画像をグループ化し、グループに文章コメントを付ける。
- 画像の特定部分を指す注釈や矢印等は不要という意向。
- 別途画像ライブラリを用意する方式や、複数ボードは今回選択されなかった。

これらは対話で確認した構想上の意向であり、確定した要求・仕様ではない。自動整列機能そのものを将来にわたり禁止するという意向は確認していない。

### 魅力と価値仮説

- 本人の関心：画像収集と、集めた画像を見渡して着想を得る体験。
- AIの価値仮説：自由配置によって画像同士の関係を自分なりに表し、グループと文章コメントによって気づきを整理できる可能性がある。
- AIの価値仮説：一画面に多くの画像が見えることで、複数のリファレンスを比較したり、組み合わせを発見したりしやすくなる可能性がある。
- 独自性・試しやすさ：未評価。競合に対する優位性や実現性を確認済みとは扱わない。
- 他の候補との関係：現時点で独立した別案は記録していない。対話中に提示した体験仮説は、ユーザーが選択した機能とは扱わない。
