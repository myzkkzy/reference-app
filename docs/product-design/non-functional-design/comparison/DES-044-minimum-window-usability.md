# DES-044：最小画面での操作性

- 設計状態：ドラフト
- 分割元：[DES-005](../../screen-design/DES-005-screen-overview.md)。本文の意味・数値・保証範囲を保持した整理であり、新たな合意・設計完了・試験合格を表さない。
- 目的・範囲：最小画面での操作性の詳細を管理する。操作、データ項目、画面配置、通信項目の正本は依存設計を参照する。
- 参照要件：[REQ-004](../../../product-requirements/functional-requirements/comparison/REQ-004-board-overview-and-detail.md)、[REQ-035](../../../product-requirements/non-functional-requirements/comparison/REQ-035-minimum-window-usability.md)。現在の合意状況と受入条件は各要件本文を正本とする。
- 依存設計：[DES-005](../../screen-design/DES-005-screen-overview.md)

## 操作性の条件

最小内側論理サイズ480×320でも設定・確認・メモ編集を含む必要操作へ到達できる。最前面・Undo／Redo・文字サイズ・グリッド／スナップ設定をすべて到達可能にする。画面配置・折畳み・スクロール・固定フッターの定義は[DES-005](../../screen-design/DES-005-screen-overview.md#狭い画面の配置契約)を参照する。

## 検証観点と未決事項

要件担当へ：REQ-004・005・010・020の制約として最小内側480×320、狭い幅で全操作到達可能を反映。正常受入案は最小寸法で操作・設定・確認フッターを使用できること。異常受入案は縮小・リサイズ中に未確定編集を消さず、隠れた破棄操作を既定にしないこと。Windows高DPI・フォーカス・支援技術の成立は検証担当へ引き継ぐ。
