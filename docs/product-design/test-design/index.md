# テスト設計：文書案内

- [DES-047：画像取込・変換のテスト設計](DES-047-image-import-test-design.md) - 全取込経路、静止画化と色・寸法変換、部分成功、時間制限、配置・表示終結を条件とケースへ具体化する。
- [DES-048：ボード表示・参照維持・編集・メモのテスト設計](DES-048-board-interaction-test-design.md) - 表示、画像・グループ・メモ編集、履歴、スナップ、最小画面と文字容量の条件・ケース・データ・手順を設計する。
- [DES-049：保存・設定・再開・別PC・作業先のテスト設計](DES-049-persistence-workflow-test-design.md) - 保存要求と設定分離、未保存保護、別PC再開、フォント調整、排他と再試行の機能フローを条件・ケース・準備仕様へ具体化する。
- [DES-050：保存整合性・障害復旧・画像実体保護のテスト設計](DES-050-save-integrity-recovery-test-design.md) - 保存の成功境界と段階障害、復旧記録の照合、画像実体の参照保持を条件・ケースと準備仕様へ具体化する。
- [DES-051：IPC契約のテスト設計](DES-051-ipc-contract-test-design.md) - IPCの共通型、22コマンドと14通知の通信・順序・照会・資源寿命を条件とケース、準備仕様へ具体化する。
- [DES-052：容量上限・安全な読込・表示資源のテスト設計](DES-052-resource-validation-test-design.md) - 保存形式の各容量境界、安全な候補検証と表示資源の予約・解放を条件とケースへ具体化する。
- [DES-053：操作・細部表示・再開・取込性能のテスト設計](DES-053-performance-test-design.md) - 初期版の500枚評価条件と各3回全回合格を保持し、性能ケース・観測仕様と未決の判定保留を記載する。
- [DES-054：Windows向けポータブル配布のテスト設計](DES-054-portable-distribution-test-design.md) - 一般利用者権限での配布成立、同梱依存と実行パス、主要操作と更新時データ保護をケース・環境仕様へ具体化する。
