- [DES-055：画像取込・変換のテーマ別テスト戦略](DES-055-image-import-test-strategy.md) - 画像入力から変換・配置・表示終結までの主要リスクに対し、層分担、網羅、観測と依存制御の方針を定める。

- [DES-057：保存・設定・再開・別PC・作業先のテーマ別テスト戦略](DES-057-persistence-workflow-test-strategy.md) - 保存要求・設定分離・再開調整・所有の主要リスクに対し、層分担、網羅、観測と依存制御の方針を定める。
- [DES-058：保存整合性・障害復旧・画像実体保護のテスト戦略](DES-058-save-integrity-recovery-test-strategy.md) - 保存成功と異常終了後の復元、再試行、画像実体と正常コピーの保護を確認する層・網羅・観測の判断を定める。

- [DES-060：容量上限・安全な読込・表示資源のテスト戦略](DES-060-resource-validation-test-strategy.md) - 容量境界、全体候補の安全な検証、表示資源の予約・解放・取消を確認する層と網羅・観測の判断を定める。
- [DES-061：操作・細部表示・再開・取込性能のテスト戦略](DES-061-performance-test-strategy.md) - 既定の500枚負荷・性能値・各3回全回合格を維持し、実表示と実保存に基づく測定・網羅方針と未決依存の判定保留を定める。
- [DES-062：Windows向けポータブル配布のテスト戦略](DES-062-portable-distribution-test-strategy.md) - 選択済みのWindows対象と固定WebView2方式に基づき、同梱依存、一般利用者の主要経路と更新時のデータ保護を確認する方針を定める。
