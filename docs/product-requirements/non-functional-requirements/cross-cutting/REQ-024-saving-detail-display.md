# REQ-024：保存中の細部表示

- 種類：非機能
- 参照要求：[DEM-002](../../../product-demands/comparison/DEM-002-compare-image-overviews.md#dem-002多くの画像を見渡し全体と細部を比較する)、[DEM-004](../../../product-demands/cross-cutting/DEM-004-resume-saved-work.md#dem-004蓄積内容を保ち後日再開する)
- 参照時点の要求：DEM-002「多数の画像を見渡し制作中にも細部を照合する」、DEM-004「画像・配置・グループ・メモを保ち後日再開する」。参照要求はいずれも合意済み。
- 内容：自動保存中・手動保存中はズーム操作停止から対象画像の細部表示完了まで2秒以内とする。
- 適用条件：利用者のWindows 11初期版での共通評価条件に基づく利用。
- 業務ルール・例外：緩和は自動保存・手動保存の処理中に限る。いずれの保存中もパン・ズームを継続できる。
- 優先度・理由：必須。多数の画像を見渡し制作中にも細部を照合する・画像・配置・グループ・メモを保ち後日再開するという初期成果を、今回回答された保存中の細部表示の振る舞い・条件で満たすため。
- 根拠・出典：上記参照要求、[現行5要求への合意](../../../product-demands/product-decisions/2026-09-13-final-demand-agreement.md#決定内容)、今回の要件定義対話でのユーザーの回答（親エージェント経由の要約）。数値と評価環境・画像構成・全3回合格はユーザーの選択。実測による確認ではない。 未決事項インタビューにおけるユーザーの回答：手動保存中にも自動保存中と同じ基準を適用し、操作を継続できることを求める。測定の具体手順は設計・検証へスキップする。 現在の合意：ユーザーは現行本文・受入条件・優先度（必須）を含む本要件を条件付き合意とする分類に明示的に合意。根拠：提示した26要件の分類を指定した「これに合意状況を遷移させてください」との回答。 各未決事項の引継ぎ先・確定時期・解消条件・進めてよい範囲を含む条件付き合意であり、未決値そのものの確定や最終的な受入判定を意味しない。
- 合意状況：条件付き合意
- 依存要件：[REQ-012](../../functional-requirements/cross-cutting/REQ-012-periodic-autosave.md#req-01230秒ごとの自動保存)、[REQ-014](../../functional-requirements/cross-cutting/REQ-014-manual-save.md#req-014手動保存)、[REQ-022](REQ-022-normal-detail-display.md#req-022通常時の細部表示)
- 未決事項：スキップ（設計・検証へ引継ぎ）：[性能の共通評価条件](REQ-033-performance-evaluation-conditions.md#性能の共通評価条件)に記載した画像実体・ボード状態・入力手順・計測方法は、指定の工程で確定する。確定まで完全な受入判定は保留する。 影響：評価負荷と合否の再現性に関わる。解消条件：共通評価条件の4項目を既記載の担当・時期に固定し、既存の閾値・画像構成・全3回合格を維持した評価条件へのユーザーの合意を得る。条件付き合意後に進めてよい範囲：確定した性能目標に基づく設計・試作・予備計測。最終的な受入判定は条件確定・合意後に行う。
