# REQ-003：複数取込と失敗通知

- 種類：機能
- 参照要求：[DEM-001](../../product-demands/collection/DEM-001-collect-reference-images.md#dem-001比較したい参考画像を継続して蓄積する)
- 参照時点の要求：DEM-001「参考画像を取り込み継続して蓄積する」。参照要求はいずれも合意済み。
- 内容：複数ローカルファイルを一括で取り込み、正常な画像は追加し、失敗した対象と理由を通知する。
- 適用条件：利用者のWindows 11初期版での単一ボードの利用。
- 業務ルール・例外：ドラッグ＆ドロップ・ファイルダイアログの両経路で本要件を適用し、以下の正常・異常ケースをそれぞれ確認する。破損・非対応等で取り込めない画像が混在しても正常分を追加する。
- 追加ルール：画像ごとの変換は開始から120秒で打ち切る。異常終了・メモリ不足・上限超過は対象画像の失敗とし、正常分は追加する。同じ画像の無限自動再試行はしない。作業領域の書込み失敗はモーダルで通知する。
- 優先度・理由：必須。参考画像を取り込み継続して蓄積するという初期成果を、今回回答された複数取込と失敗通知の振る舞い・条件で満たすため。
- 根拠・出典：上記参照要求、[現行5要求への合意](../../product-demands/product-decisions/2026-09-13-final-demand-agreement.md#決定内容)、今回の要件定義対話でのユーザーの回答（親エージェント経由の要約）。 未決事項インタビューにおけるユーザーの回答：失敗理由の詳細分類・表示文言は要件定義ではスキップし、設計へ引き継ぐ。
- 変更根拠：ユーザーの計画実行指示。意味・受入条件の変更によりドラフトとし、従前の合意を変更後本文への合意とはしない。
- 合意状況：ドラフト
- 依存要件：[REQ-001](REQ-001-add-image-path.md#req-001画像の追加経路)、[REQ-002](REQ-002-static-image-formats.md#req-002静止画形式と複数フレームの扱い)
- 未決事項：スキップ（設計へ引継ぎ）：失敗理由の詳細分類・表示文言は設計時に確定する。通知する業務内容は失敗した対象と理由で確定している。

### 受入条件

| ケース | 前提 | 操作・事象 | 期待結果 |
| --- | --- | --- | --- |
| 正常 | 複数の読取可能画像がある | 一括で追加する | 正常画像がすべて追加される |
| 異常 | 正常画像と破損画像・非対応ファイルが混在する | 一括で追加する | 正常分が追加され、失敗対象と理由が分かる |
| 異常 | すべて読取不能である | 一括で追加する | 画像は追加されず、追加失敗の対象と理由が分かる |
| 異常 | 正常画像と変換失敗対象が混在する | 変換が120秒超過・異常終了・メモリ不足となる | 失敗対象と理由を通知し途中成果は追加しない。次の対象を処理して正常分を追加する |
