# REQ-026：ローカル500枚の初回取込性能

- 種類：非機能
- 参照要求：[DEM-001](../../product-demands/collection/DEM-001-collect-reference-images.md#dem-001比較したい参考画像を継続して蓄積する)
- 参照時点の要求：DEM-001「参考画像を取り込み継続して蓄積する」。参照要求はいずれも合意済み。
- 内容：空のボードにローカル500ファイルを渡してから、全画像が表示され操作可能になるまで30秒以内とする。
- 適用条件：利用者のWindows 11初期版での共通評価条件に基づく利用。
- 業務ルール・例外：自動保存完了は取込完了条件に含めない。登録上限ではない。ファイルダイアログで選択している時間は計測に含めず、選択を確定してファイルをボードへ渡してから計測する。
- 優先度・理由：必須。参考画像を取り込み継続して蓄積するという初期成果を、今回回答されたローカル500枚の初回取込性能の振る舞い・条件で満たすため。
- 根拠・出典：上記参照要求、[現行5要求への合意](../../product-demands/product-decisions/2026-09-13-final-demand-agreement.md#決定内容)、今回の要件定義対話でのユーザーの回答（親エージェント経由の要約）。数値と評価環境・画像構成・全3回合格はユーザーの選択。実測による確認ではない。 未決事項インタビューにおけるユーザーの回答：各試行前にアプリを再起動する。画像群の代表性を確定し、実ファイル・ボード状態・入力手順・計測方法は検証へスキップする。 現在の合意：ユーザーは現行本文・受入条件・優先度（必須）を含む本要件を条件付き合意とする分類に明示的に合意。根拠：提示した26要件の分類を指定した「これに合意状況を遷移させてください」との回答。 各未決事項の引継ぎ先・確定時期・解消条件・進めてよい範囲を含む条件付き合意であり、未決値そのものの確定や最終的な受入判定を意味しない。
- 合意状況：条件付き合意
- 依存要件：[REQ-001](../collection/REQ-001-add-image-path.md#req-001画像の追加経路)、[REQ-002](../collection/REQ-002-static-image-formats.md#req-002静止画形式と複数フレームの扱い)、[REQ-003](../collection/REQ-003-batch-import-errors.md#req-003複数取込と失敗通知)
- 未決事項：スキップ（設計・検証へ引継ぎ）：[性能の共通評価条件](REQ-033-performance-evaluation-conditions.md#性能の共通評価条件)に記載した画像実体・ボード状態・入力手順・計測方法は、指定の工程で確定する。確定まで完全な受入判定は保留する。 影響：評価負荷と合否の再現性に関わる。解消条件：共通評価条件の4項目を既記載の担当・時期に固定し、既存の閾値・画像構成・全3回合格を維持した評価条件へのユーザーの合意を得る。条件付き合意後に進めてよい範囲：確定した性能目標に基づく設計・試作・予備計測。最終的な受入判定は条件確定・合意後に行う。
