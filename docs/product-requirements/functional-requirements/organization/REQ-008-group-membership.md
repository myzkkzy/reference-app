# REQ-008：グループへの所属と解除

- 種類：機能
- 参照要求：[DEM-003](../../../product-demands/organization/DEM-003-organize-image-insights.md#dem-003画像の関係や気づきを自分なりに整理する)
- 参照時点の要求：DEM-003「配置・グループと独立メモで意図を整理する」。参照要求はいずれも合意済み。
- 内容：利用者がボード上の画像・メモからグループを作成できる。画像・メモの所属はそれぞれ最大1グループ（未所属可）とし、追加・除外・グループ解除ができる。所属済み要素を別グループに追加すると所属を移し、位置を維持する。
- 編集共通ルール：[編集履歴と重なり順](REQ-027-edit-history-and-stacking.md#編集履歴と重なり順の共通ルール)を適用する。
- 配置共通ルール：[配置・グリッド・スナップ](REQ-028-placement-grid-and-snapping.md#配置グリッドスナップの共通ルール)を適用する。
- 適用条件：利用者のWindows 11初期版での単一ボードの利用。
- 業務ルール・例外：除外・グループ解除で画像・メモ自体を削除しない。画像もメモも0件になった空グループを残し、後から要素を追加できる。メモはグループへの所属なしでも利用できる。
- 追加ルール：グループの新規作成・所属操作にも[利用上限](../../non-functional-requirements/cross-cutting/REQ-029-image-and-project-limits.md#画像とプロジェクトの利用上限)を適用する。上限を満たせない変更は既存状態を変更せず理由を通知する。
- 枠のルール：各辺24ボード単位の余白、最小64×64。作成時は内容外周＋余白を含め最小寸法以上とし、空枠は64×64。所属要素の有無にかかわらず手動変更でき、内容外周＋余白と最小寸法を下回らない。枠変更で中身を移動・拡縮しない。通常保持し必要時だけ拡大する。削除・内側移動で自動縮小せず「中身に合わせる」で調整する。空グループの同操作は無効。全枠を保存・復元する。
- 優先度・理由：必須。配置・グループと独立メモで意図を整理するという初期成果を、グループへの所属と解除の振る舞い・条件で満たすため。
- 根拠・出典：[グループ所属とメモ容量の条件](../../../product-demands/product-decisions/2026-10-14-board-membership-and-note-capacity.md#決定内容)、[ボード編集・履歴・スナップの反映判断](../../../product-demands/product-decisions/2026-10-06-board-editing-and-snap.md#決定内容)、[全体表示・再開倍率・メモ表示の反映判断](../../../product-demands/product-decisions/2026-10-06-board-view-and-note-display.md#決定内容)、[画像とプロジェクトの利用上限の反映判断](../../../product-demands/product-decisions/2026-10-06-image-and-project-limits.md#決定内容)。参照要求の期待成果と、各記録の決定内容・適用範囲を具体化する。
- 合意状況：合意済み
- 依存要件：[REQ-006](REQ-006-image-transform.md#req-006画像の移動回転拡縮)、[REQ-010](REQ-010-independent-notes.md#req-010独立メモの編集と配置)
- 未決事項：本要件と共通ルールの振る舞い・数値境界は具体化済み。設計担当は実装引継ぎ前に本文・受入条件との一致をレビューし、検証担当は受入実施前に組合せ操作と異常処理の成立を確認する。解消条件は記載した期待結果の成立。設計・検証に残る入力方式・ライブラリ・実機確認を、利用者の未回答扱いに戻さない。現在の合意状況は冒頭の既存項目を参照する。設計照合と実機確認は後続へ引き継ぐ。

### 受入条件

| ケース | 前提 | 操作・事象 | 期待結果 |
| --- | --- | --- | --- |
| 正常 | ボードに未所属の画像・メモがある | 利用者が画像・メモからグループを作成する | グループが作成され、対象の画像・メモが所属する |
| 正常 | 未所属の画像・メモとグループがある | 画像・メモを追加し、その後除外する | 所属の追加・解除が反映され、画像・メモとその位置は維持される |
| 正常 | 画像・メモがあるグループに所属している | 別グループに追加する | 旧所属が外れて新所属になり、位置が変わらない |
| 正常 | 画像・メモを含むグループがある | グループを解除する | グループが解除され、画像・メモとその位置は維持される |
| 正常 | 画像またはメモが1件だけ所属するグループがある | 最後の要素を除外・削除・別グループへ移す操作をそれぞれ確認する | 画像もメモも0件の空グループが残り、後から画像・メモを追加できる |
| 異常 | 画像・メモ・グループの合計が100,000要素 | グループを新規作成する | 超過を通知し、既存グループや所属を保持する |
| 正常 | 所属画像・メモがある | 枠を手動で広げ、要素を削除・内側へ移動する | 広げた枠を保持し、中身の寸法・位置を枠変更だけで変えない |
| 正常 | 所属要素が保持枠に収まらなくなる | 要素を移動・拡縮またはメモの高さを変える | 必要な範囲へ枠を拡大する |
| 正常 | 中身より広い枠がある | 「中身に合わせる」を行う | 各辺24の余白と64×64以上を満たす枠へ調整し、Undoで以前の枠へ戻せる |
| 正常 | 空または非空グループの枠を変更済み | 保存して再開する | 変更した枠を復元する |
| 正常 | 空グループまたは小さい内容がある | 枠を作成・変更する | 64×64以上を維持し、空の「中身に合わせる」は無効。内容ありは各辺24の余白を満たす |
| 異常 | 内容＋余白または64×64を下回る枠操作 | 小さくしようとする | 制約を破る状態を確定せず、内容の位置・大きさを変更しない |
