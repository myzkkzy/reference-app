# REQ-017：未保存での終了

- 種類：機能
- 参照要求：[DEM-004](../../../product-demands/cross-cutting/DEM-004-resume-saved-work.md#dem-004蓄積内容を保ち後日再開する)
- 参照時点の要求：DEM-004「画像・配置・グループ・メモを保ち後日再開する」。参照要求はいずれも合意済み。
- 内容：ボード・表示位置・設定の未保存がある場合、保存して終了・破棄して終了・編集に戻るを選べる。終了のための保存に失敗しても自動終了しない。
- 適用条件：利用者のWindows 11初期版での単一ボードの利用。
- 業務ルール・例外：破棄は未保存内容を対象とする。 取込中は完了を待ち、待機取消で現在のボードへ戻れる。取込自体は中止しない。新たな定期保存・設定保存の開始を止め、実行中保存と受付済み手動保存の結果を待つ。未確定入力は編集完了・取消・戻るで解消してから残る未保存を確認する。保存はボード・表示位置・設定を含め、成功後だけ終了する。破棄は未保存分と保留要求だけが対象で、既に独立保存した設定を巻き戻さない。戻るでは設定保存を再開し、保留周期はREQ-012に従う。保存待ち中に戻る場合は終了要求だけを取り消し、後着の成功で終了しない。
- 保存・排他共通ルール：[同一ファイル利用と保存再試行](REQ-032-file-lock-and-save-retry.md#同一ファイル利用と保存再試行の共通ルール)を適用する。
- 今回の反映根拠：ユーザーのセッション決定と要件反映計画実行指示。[設定と再開の判断](../../../product-demands/product-decisions/2026-10-06-project-settings-and-font-resumption.md#決定内容)および[同一ファイル利用と再試行の判断](../../../product-demands/product-decisions/2026-10-06-project-lock-and-save-retry.md#決定内容)の決定内容に基づく反映。技術方式の採用、REQ全体の合意、実機試験は区別する。
- 優先度・理由：必須。画像・配置・グループ・メモを保ち後日再開するという初期成果を、今回回答された未保存での終了の振る舞い・条件で満たすため。
- 根拠・出典：上記参照要求、[現行5要求への合意](../../../product-demands/product-decisions/2026-09-13-final-demand-agreement.md#決定内容)、今回の要件定義対話でのユーザーの回答（親エージェント経由の要約）。 現在の根拠：ユーザーの保存方式に関する個別回答と「保存処理の統合と、異常終了後の復元設計」の実行指示。合意済み本文を変更したため現在はドラフト。個別の方針決定と変更後REQ全体の合意・試験合格は区別する。
- 合意状況：ドラフト
- 依存要件：[REQ-014](REQ-014-manual-save.md#req-014手動保存)、[REQ-016](REQ-016-save-failure-recovery.md#req-016保存失敗時の内容保護と再試行)
- 未決事項：保存・排他・再試行と本項の振る舞いは具体化済み。変更後本文・受入条件は合意レビュー待ち。設計担当は実装引継ぎ前に要件との一致・ライブラリ選定を確認し、検証担当は受入実施前に保存障害・異常終了・外部変更・設定分離と該当する入力境界の成立を確認する。解消条件は本項・共通受入条件の成立。技術選定と具体的試験手順は設計・検証側に保持する。

### 受入条件

| ケース | 前提 | 操作・事象 | 期待結果 |
| --- | --- | --- | --- |
| 正常 | 未保存変更がある | 保存して終了を選ぶ | 保存成功後に終了し、再開で内容を確認できる |
| 正常 | 未保存変更がある | 破棄して終了を選ぶ | 未保存変更を破棄して終了する |
| 正常 | 未保存変更がある | 戻るを選ぶ | 終了せず編集中内容を保つ |
| 異常 | 終了時の保存が失敗する | 保存して終了を選ぶ | 自動終了せず、未保存内容を保持する |
| 正常 | 画像取込中である | 終了を要求し、待機を取り消す | 取込を中断せず現在のボードへ戻る。待機を続ければ完了後に未保存を確認する |
| 正常 | ボード変更が未保存で、設定の独立保存は成功済みである | 破棄して終了する | ボード未保存分だけ破棄し、保存済み設定は維持する |
| 正常 | 設定保存が保留または失敗して未保存である | 終了を要求する | 設定も確認対象となり、保存・破棄・戻るを選べる |
| 正常 | 終了のため保存中である | 編集に戻り、その後保存が成功する | 保存は完了しても自動終了しない |
| 異常 | 保存再試行または終了保存を待っている | 戻るを選び、その後中断処理が完了する | 編集を保持し後着完了で自動終了しない。残る未保存を保存済みとしない |
| 正常 | フォント差で枠・座標が未保存になった | 終了する | 無通知座標補正でも未保存保護を適用し、保存・破棄・戻るを選べる |
