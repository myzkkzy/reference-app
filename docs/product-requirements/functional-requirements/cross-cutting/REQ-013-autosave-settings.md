# REQ-013：自動保存設定

- 種類：機能
- 参照要求：[DEM-004](../../../product-demands/cross-cutting/DEM-004-resume-saved-work.md#dem-004蓄積内容を保ち後日再開する)
- 参照時点の要求：DEM-004「画像・配置・グループ・メモを保ち後日再開する」。参照要求はいずれも合意済み。
- 内容：同じアプリ配置先の全プロジェクト共通で自動保存の有効・無効を切り替えられる。初期値は有効。設定変更は即時適用し、ボードの未保存編集とは独立して自動的に保存する。設定保存成功後は再起動後も保持する。
- 適用条件：利用者のWindows 11初期版での単一ボードの利用。
- 業務ルール・例外：無効時も手動保存は利用できる。有効へ切り替えた時点をREQ-012の30秒周期の起算点とする。 自動保存を無効にした変更も、追加の手動保存なしで保存する。設定だけの保存では未保存の画像・配置・グループ・メモ・表示位置を保存しない。失敗でも適用値と編集中内容を保持し、設定保存失敗と未保存を表示して再試行できる。ボードの手動保存は共通設定を保存しない。設定画面を閉じても変更を取り消さない。別プロジェクトへ切り替えても共通設定と未保存状態を維持する。復旧用保持は独立した共通設定項目で初期有効、同じ設定保存方式を使う。設定保存の停止と保護はアプリ終了時に適用し、ボード切替では継続する。
- 保存・排他共通ルール：[同一ファイル利用と保存再試行](REQ-032-file-lock-and-save-retry.md#同一ファイル利用と保存再試行の共通ルール)を適用する。
- 根拠・出典：[保存完了と再開の保証範囲](../../../product-demands/product-decisions/2026-10-14-save-completion-and-resumption-policy.md#決定内容)、[設定の独立保存とフォント差再開の反映判断](../../../product-demands/product-decisions/2026-10-06-project-settings-and-font-resumption.md#決定内容)、[同一ファイル利用と保存再試行の判断](../../../product-demands/product-decisions/2026-10-06-project-lock-and-save-retry.md#決定内容)。参照要求の期待成果と、各記録の決定内容・適用範囲を具体化する。
- 設定共通ルール：[設定の保存・失敗・適用範囲](REQ-030-shared-settings.md#設定の共通ルール)に従う。
- 優先度・理由：必須。画像・配置・グループ・メモを保ち後日再開するという初期成果を、自動保存設定の振る舞い・条件で満たすため。
- 合意状況：ドラフト（共通設定への統合・ボード分離の変更部分は再レビュー対象）
- 依存要件：[REQ-012](REQ-012-periodic-autosave.md#req-01230秒ごとの自動保存)、[REQ-014](REQ-014-manual-save.md#req-014手動保存)
- 未決事項：保存・排他・再試行と本項の振る舞いは具体化済み。合意状況は冒頭の既存項目を参照する。設計担当は実装引継ぎ前に要件との一致・ライブラリ選定を確認し、検証担当は受入実施前に保存障害・異常終了・外部変更・設定分離と該当する入力境界の成立を確認する。解消条件は本項・共通受入条件の成立。技術選定と具体的試験手順は設計・検証側に保持する。

### 受入条件

| ケース | 前提 | 操作・事象 | 期待結果 |
| --- | --- | --- | --- |
| 正常 | 設定をまだ変更していない初回利用 | 自動保存設定を確認する | 有効になっている |
| 正常 | 設定を無効に変更し、設定保存が成功する | 再起動し、編集して30秒以上経過させる | 無効設定が保持され、自動保存されない。手動保存できる |
| 正常 | 無効設定である | 有効に変更し、設定保存成功後に再起動する | 有効設定が保持される |
| 正常 | 自動保存が無効で未保存変更がある | 有効に切り替え、30秒経過させる | 有効化から30秒を起算し、自動保存が行われる |
| 正常 | 保存済み画像を移動したが未保存である | 自動保存を無効にして設定保存成功後、ボード変更を破棄して再開する | 無効設定は残り、画像は移動前の保存位置となる |
| 異常 | 設定保存が失敗する | 設定を変更し、原因解消後に再試行する | 適用中の値と編集内容は保ち、設定の保存失敗・未保存を示す。再試行成功後に再起動して設定を復元できる |
| 正常 | 異なる二つのプロジェクトと未保存の共通設定がある | 切り替える | 同じ共通設定と未保存状態を使い続ける |
| 正常 | グリッド・スナップ・回転刻みの設定が変更可能 | 各設定を変更し再開する | 設定共通ルールに従い即時適用・独立保存・復元する。ボード未保存を混入しない |

- 変更根拠：[共通設定とボード分離の判断](../../../product-demands/product-decisions/2026-10-17-common-settings-and-board-separation.md)。設定の範囲・保存先・適用時点はREQ-030を正本とし、変更範囲の詳細レビューと製品検証は未完了。
