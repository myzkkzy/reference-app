# REQ-011：保存内容の復元

- 種類：機能
- 参照要求：[DEM-004](../../../product-demands/cross-cutting/DEM-004-resume-saved-work.md#dem-004蓄積内容を保ち後日再開する)
- 参照時点の要求：DEM-004「画像・配置・グループ・メモを保ち後日再開する」。参照要求はいずれも合意済み。
- 内容：画像・配置・グループ・独立メモに加え、表示中心・倍率をボードへ保存し、後日再開時に復元できる。配置には画像の位置・回転・表示サイズを含める。
- 適用条件：利用者のWindows 11初期版での単一ボードの利用。
- 業務ルール・例外：画像・メモそれぞれのグループ所属、要素間の相対配置、メモの文章、空グループも復元する。破損した保存内容は開かず、対象と理由を通知し、破損ファイルと現在のボードを変更しない。別の保存内容を選び直せる。保存内容の切替時の未保存変更保護・誤選択時の選び直しは、同一PC内でも[REQ-019](REQ-019-cross-pc-transfer.md#req-019利用者の別pcへの引継ぎ)のルールと受入条件を適用する。Undo／Redo履歴はセッション内だけ保持し、プロジェクトに保存しない。 新規作成では保存場所と名前を指定し、空のプロジェクトの初回保存成功後に編集を開始する。保存先選択の取消では新規作成しない。初回保存失敗では編集開始せず再試行・別保存先・取消を選べる。既存ボードがある場合はその未保存保護と初回保存成功後に切り替える。
- 追加ルール：読込は[利用上限](../../non-functional-requirements/cross-cutting/REQ-029-image-and-project-limits.md#画像とプロジェクトの利用上限)を検証し、全体が正常な場合だけ切り替える。過大な内部PNGを自動縮小して修復せず、一部だけの読込もしない。
- 関連判断の適用：画像・メモの重なり順、空・非空を問わない全グループの保持枠、メモ幅・文字サイズを保存・復元する。全8項目の共通設定はプロジェクトへ含めず、起動中アプリの設定を使う。
- 根拠・出典：[保存完了と再開の保証範囲](../../../product-demands/product-decisions/2026-10-14-save-completion-and-resumption-policy.md#決定内容)、[設定の独立保存とフォント差再開の反映判断](../../../product-demands/product-decisions/2026-10-06-project-settings-and-font-resumption.md#決定内容)、[同一ファイル利用と保存再試行の判断](../../../product-demands/product-decisions/2026-10-06-project-lock-and-save-retry.md#決定内容)、[画像とプロジェクトの利用上限の反映判断](../../../product-demands/product-decisions/2026-10-06-image-and-project-limits.md#決定内容)。参照要求の期待成果と、各記録の決定内容・適用範囲を具体化する。
- 保存・排他共通ルール：[同一ファイル利用と保存再試行](REQ-032-file-lock-and-save-retry.md#同一ファイル利用と保存再試行の共通ルール)を適用する。
- 設定共通ルール：[設定の保存・失敗・適用範囲](REQ-030-shared-settings.md#設定の共通ルール)に従う。
- 再開調整ルール：[フォント差による再開調整](REQ-031-font-resumption-adjustments.md#フォント差による再開調整の共通ルール)を適用する。
- 優先度・理由：必須。画像・配置・グループ・メモを保ち後日再開するという初期成果を、保存内容の復元の振る舞い・条件で満たすため。
- 合意状況：ドラフト（共通設定への統合・ボード分離の変更部分は再レビュー対象）
- 依存要件：[REQ-006](../organization/REQ-006-image-transform.md#req-006画像の移動回転拡縮)、[REQ-008](../organization/REQ-008-group-membership.md#req-008グループへの所属と解除)、[REQ-010](../organization/REQ-010-independent-notes.md#req-010独立メモの編集と配置)
- 未決事項：保存・排他・再試行と本項の振る舞いは具体化済み。合意状況は冒頭の既存項目を参照する。設計担当は実装引継ぎ前に要件との一致・ライブラリ選定を確認し、検証担当は受入実施前に保存障害・異常終了・外部変更・設定分離と該当する入力境界の成立を確認する。解消条件は本項・共通受入条件の成立。技術選定と具体的試験手順は設計・検証側に保持する。

### 受入条件

| ケース | 前提 | 操作・事象 | 期待結果 |
| --- | --- | --- | --- |
| 正常 | 画像を移動・回転・拡縮し、画像・メモの混在グループ、未所属メモ、空グループを保存完了している | 終了して再開する | 画像、位置・角度・表示サイズ、画像・メモのグループ所属と相対配置、メモ文章・位置、空グループが復元される |
| 異常 | 現在のボードに編集中の内容があり、別の保存内容が破損している | 破損した保存内容を開こうとする | 開けない対象と理由が分かり、破損ファイルと現在のボードが変更されない。別の保存内容を選べる |
| 正常 | 保存済みのボードと表示中心・倍率がある | 終了して同じ内容を開く | ボードと表示中心・倍率を復元し、現在の共通設定を維持する |
| 正常 | 新規作成を開始する | 保存場所と名前を指定する／選択を取り消す | 空のプロジェクトの初回保存成功後に編集可能となる。取消では作成しない |
| 異常 | 新規プロジェクトの初回保存が失敗する | 作成を試みる | 編集開始せず失敗を示し、再試行・別保存先・取消を選べる。既存ボードは保持する |
| 異常 | manifest・DB・PNG・ZIP件数・要素数・総量のいずれかが超過 | 開く | 一部だけを採用せず、現在のボードと入力ファイルを保持する |
| 正常 | 各資源上限の直前または一致で、他の検証も満たす | 開く | 上限に一致することだけを理由に拒否しない |
| 正常 | 重なり順、非空・空グループの枠、メモ幅を変更して保存した | 終了して再開する | 保存した順・枠・幅を復元し、メモの高さは本文・幅に追従する。セッションのUndo／Redo履歴は復元しない |
| 正常 | 本文・幅・文字サイズとグリッド／スナップ設定を保存済み | 終了して再開する | 本文・幅・文字サイズ・表示中心倍率を復元し、設定はアプリ共通値を使い、高さ・必要枠調整はフォント差共通ルールに従う |
| 異常 | 別プロセスで使用中または排他確認に失敗する候補 | 開く | 同一ファイルを採用せず理由を通知し、現在ボードと対象ファイルを保持する |

- 変更根拠：[共通設定とボード分離の判断](../../../product-demands/product-decisions/2026-10-17-common-settings-and-board-separation.md)。設定の範囲・保存先・適用時点はREQ-030を正本とし、変更範囲の詳細レビューと製品検証は未完了。

## 文脈

画像処理・資源管理・読込制限と関連する編集・保存の条件は、本文および根拠文書の決定範囲に従う。現在の合意状況は各要件本文の既存項目を正本とする。

利用者による収集・比較・整理を保存し、同じ利用者が別PCで再開する。現在の合意状況は各要件本文を参照する。

各要件は参照要求と判断記録を具体化する。合意状況は各要件本文の既存項目を正本とし、条件付き合意の未決事項は後続工程へ引き継ぐ。実装完了・試験合格は別に確認する。
