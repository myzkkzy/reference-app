# REQ-012：30秒ごとの自動保存

- 種類：機能
- 参照要求：[DEM-004](../../../product-demands/cross-cutting/DEM-004-resume-saved-work.md#dem-004蓄積内容を保ち後日再開する)
- 参照時点の要求：DEM-004「画像・配置・グループ・メモを保ち後日再開する」。参照要求はいずれも合意済み。
- 内容：自動保存が有効な間、ボードが利用可能になった時または自動保存を有効にした時から30秒の固定周期で、確定済みボード・表示位置の未保存変更があれば保存する。
- 適用条件：利用者のWindows 11初期版での単一ボードの利用。
- 業務ルール・例外：編集・手動保存で周期をリセットしない。未保存変更がなければ保存処理を行わず、保存済み状態と周期を維持する。前回保存中に次の時刻を迎えても保存を同時実行せず、保存完了後に未保存変更があれば最新内容を続けて1回保存する。定期周期は維持する。保存状態と失敗時の内容保護・再試行はREQ-015・016に従う。 設定変更による独立保存はREQ-013に従い、定期保存の有効・無効と区別する。パン・ズームだけの変更も保存対象。メモ入力中はIME変換中の部分を除く入力済み文章を保存対象として確定し、入力を継続できる。編集取消の基点はこの確定地点へ進む。配置ドラッグ中は開始前の位置・順序・枠を保存し、途中配置・前面化を含めない。終了・切替確認中は新たな定期保存・設定保存を開始せず、到来した周期を最大1回へ保留する。戻った際に有効で未保存があれば1回保存し、その後も元の固定周期を維持する。無効化時は保留定期要求を取り消す。
- 保存・排他共通ルール：[同一ファイル利用と保存再試行](REQ-032-file-lock-and-save-retry.md#同一ファイル利用と保存再試行の共通ルール)を適用する。
- 今回の反映根拠：ユーザーのセッション決定と要件反映計画実行指示。[設定と再開の判断](../../../product-demands/product-decisions/2026-10-06-project-settings-and-font-resumption.md#決定内容)および[同一ファイル利用と再試行の判断](../../../product-demands/product-decisions/2026-10-06-project-lock-and-save-retry.md#決定内容)の決定内容に基づく反映。技術方式の採用、REQ全体の合意、実機試験は区別する。
- 優先度・理由：必須。画像・配置・グループ・メモを保ち後日再開するという初期成果を、今回回答された30秒ごとの自動保存の振る舞い・条件で満たすため。
- 根拠・出典：上記参照要求、[現行5要求への合意](../../../product-demands/product-decisions/2026-09-13-final-demand-agreement.md#決定内容)、今回の要件定義対話でのユーザーの回答（親エージェント経由の要約）。 未決事項インタビューにおけるユーザーの回答：ボード開始・有効化から固定周期、無変更時は保存なし、保存中の次周期は完了後に残る変更を保存する。 現在の根拠：ユーザーの保存方式に関する個別回答と「保存処理の統合と、異常終了後の復元設計」の実行指示。合意済み本文を変更したため現在はドラフト。個別の方針決定と変更後REQ全体の合意・試験合格は区別する。
- 合意状況：ドラフト
- 依存要件：[REQ-011](REQ-011-restore-saved-content.md#req-011保存内容の復元)、[REQ-015](REQ-015-save-status.md#req-015保存状態の識別)、[REQ-016](REQ-016-save-failure-recovery.md#req-016保存失敗時の内容保護と再試行)
- 未決事項：保存・排他・再試行と本項の振る舞いは具体化済み。変更後本文・受入条件は合意レビュー待ち。設計担当は実装引継ぎ前に要件との一致・ライブラリ選定を確認し、検証担当は受入実施前に保存障害・異常終了・外部変更・設定分離と該当する入力境界の成立を確認する。解消条件は本項・共通受入条件の成立。技術選定と具体的試験手順は設計・検証側に保持する。

### 受入条件

| ケース | 前提 | 操作・事象 | 期待結果 |
| --- | --- | --- | --- |
| 正常 | 自動保存が有効で、ボード利用開始から未保存変更がある | 利用開始から30秒の周期を迎える | 変更内容の自動保存が行われる |
| 正常 | 自動保存が有効で未保存変更がない | 30秒の周期を迎える | 保存処理を行わず、保存済み状態と定期周期を維持する |
| 正常 | 固定周期の途中で編集・手動保存を行い、その後さらに変更している | 次の固定周期を迎える | 編集・手動保存で起算点が変わらず、残る変更が定期時刻に保存される |
| 正常 | 前回保存が継続中に次の定期時刻となり、その保存に含まれない変更がある | 前回保存が完了する | 同時保存は行わず、完了後に最新内容を続けて1回保存する。定期周期は変わらない |
| 正常 | 前回保存が継続中に次の定期時刻となったが、完了時には未保存変更がない | 前回保存が完了する | 不要な追加保存を行わず、定期周期を維持する |
| 正常 | メモを入力中で、変換確定済み文章とIME変換中部分がある | 定期保存時刻を迎える | 確定済み文章だけを保存し、変換中部分は未保存と分かる。入力を継続できる |
| 正常 | 終了・切替確認中に複数の定期時刻を迎える | 編集に戻る | 確認中は新たな定期保存・設定保存を開始しない。戻った時点で有効かつ未保存なら1回に集約して保存し、元の周期を維持する |
| 正常 | 確認中に周期を迎えたが、自動保存が無効または未保存変更がない | 戻る | 不要な定期保存を開始しない |
| 正常 | 画像等は編集せず表示中心・倍率だけを変更した | 固定周期を迎える | 変更した表示位置を保存する |
| 正常 | 前面化を伴うドラッグ中 | 定期保存時刻を迎える | 開始前の位置・順序・枠を保存し、解放で確定する変更は後続未保存とする |
| 異常 | 置換後失敗で追加書込停止中 | 複数の定期時刻を迎える | 新たな書込を始めず編集を保持し、明示再試行で中断処理を終結後に後続変更を扱う |
