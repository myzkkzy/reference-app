## 設定の共通ルール

[共通設定とボード分離の判断](../../../product-demands/product-decisions/2026-10-17-common-settings-and-board-separation.md#決定内容)に従い、従来のプロジェクト設定とPC側アプリ設定を共通設定へ統合する。設定は全プロジェクト共通で、アプリ配置先ごとに独立する。実行ファイルの親を基準とした`./config/settings.json`へ形式版と8項目を保存する。Windowsユーザー別・プロジェクトID別の値は持たない。

| 項目 | 初期値・条件 | 適用時点 |
| --- | --- | --- |
| 自動保存・復旧用保持 | ともにオン。周期は固定30秒 | 変更確定時に即時適用 |
| グリッド表示・間隔 | オン・32。間隔8・16・32・64・128 | 変更確定時に即時適用 |
| スナップ・回転刻み | オン・15度。刻み5・15・45・90 | 変更確定時に即時適用 |
| 履歴上限 | 100、1～1,000 | 保存成功値を次の新規作成・オープン・再オープンから適用 |
| 画像作業先 | プロジェクト隣の専用フォルダー | 保存成功値を次のボード開始から適用。既定は方針として保持し、開始時に実際の場所を解決 |

- 起動時に1回読む。設定がなければ通知せず既定値で開始し、configと設定ファイルを新規作成する。作成失敗は通知し再試行できる。
- 破損・非対応版・読込失敗は通知して全既定値で開始し、既存原本を保護する。利用者が明示的に再作成する場合にだけ原本を退避してから置き換える。退避失敗では原本を置換しない。
- 確定変更を設定専用処理で保存する。保存失敗でも即時適用6項目は適用値を保持する。履歴上限・画像作業先の次回値は直前の保存成功値を維持し、成功値がない場合は通常既定値を使う。入力・未保存・再試行手段を残す。
- ボード手動・定期保存は設定を保存せず、設定保存はボードファイルと復旧用を変更しない。双方の保存成功・未保存を別々に表示する。
- プロジェクト切替・閉じるで未保存設定を捨てない。設定画面を閉じても確定済み変更を取り消さない。アプリ終了時は設定も保存・破棄・戻るで保護し、保存を選んだ場合は必要な全対象の保存成功後だけ終了する。
- 固定の保存先へ書けなくてもボード利用を継続でき、保存先を自動変更しない。同じ設定先への複数プロセスの書込みは直列化し、起動時または直前保存成功時からの外部変更を検出して競合を通知し上書きしない。他プロセスへ変更を即時配信せず、各起動時に読む。
- ボードの復旧・別PC再開では現在のアプリの共通設定を使う。設定も移送する場合は対象アプリ終了後にconfigを移す。更新では既存configを保持し、新配置先では旧configを引き継ぐ。ショートカットや作業ディレクトリーで保存先を変えない。

### 共通受入条件

| ケース | 前提 | 操作・事象 | 期待結果 |
| --- | --- | --- | --- |
| 正常 | 同じ実行ファイル、異なる作業ディレクトリー・ショートカット開始位置 | 起動する | 同じ実行ファイル配下config/settings.jsonを使う。別配置のアプリは独立 |
| 正常 | config・設定がない | 起動する | 無通知で全既定値を適用し、新規作成する |
| 異常 | 破損・未知版・読込失敗 | 起動し再作成を選ぶ | 通知して既定値で継続。原本は自動変更せず明示再作成時に退避。退避不可なら保護継続 |
| 正常 | ボードが未保存 | 設定だけを変更・保存し、続いてボードだけ保存する | 設定保存ではボード現物不変、ボード保存では設定現物不変。状態表示も独立 |
| 異常 | 設定の作成・保存が失敗 | 項目を変更し、別ボードを開始する | 前6項目の適用・未保存を保持し、後2項目は直前の成功値で開始。固定先へ再試行でき、ボードを利用できる |
| 正常 | 履歴・作業先の変更保存が成功 | 新規作成・オープン・再オープンする | 現ボードは旧値、次の開始で成功値を捕捉。既定作業先は各プロジェクト隣へ解決 |
| 正常 | 設定が未保存 | ボード切替後にアプリを終了する | 切替でも値・未保存が残り、終了で保存・破棄・戻る。片方の保存失敗では終了しない |
| 異常 | 2プロセスが同じ設定を起動時に読んだ | 一方保存後、他方が旧基準で保存する | 直列化して競合を検出し、先行成功を上書きしない |
| 異常 | 設定の一時出力・検査・同期・置換中 | 失敗・異常終了する | 旧正常設定とボードを保護し、成功未確認を保存済みと表示しない |
| 正常 | 復旧用ボード・別PC・新配置への更新 | 復旧・移送・更新する | ボード復旧で共通設定を巻き戻さない。移送先の設定を使い、明示したconfig引継ぎで設定を保持 |
| 異常 | 実際の作業先が書込不可・容量不足 | ボードを開始する | 理由を通知し自動代替せず、既存正常内容と編集中ボードを保持 |
