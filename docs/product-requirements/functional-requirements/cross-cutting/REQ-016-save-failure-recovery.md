# REQ-016：保存失敗時の内容保護と再試行

- 種類：機能
- 参照要求：[DEM-004](../../../product-demands/cross-cutting/DEM-004-resume-saved-work.md#dem-004蓄積内容を保ち後日再開する)
- 参照時点の要求：DEM-004「画像・配置・グループ・メモを保ち後日再開する」。参照要求はいずれも合意済み。
- 内容：ボード保存・設定保存の失敗時は直前の保存成功内容と編集中内容を保持する。アプリ動作中は編集を続け、未保存を確認して再試行できる。
- 適用条件：利用者のWindows 11初期版での単一ボードの利用。
- 業務ルール・例外：復旧用保持が有効なら表示位置だけを含む全ボード保存で直前1世代を入れ替える。復旧用保持が無効の場合、既存復旧用は更新・自動削除しない。退避・復旧用を開く場合は利用者の選択後に開き、元ファイルを自動修復せず別名保存する。保存成功の判定・異常終了後の保証範囲は[REQ-037](../../non-functional-requirements/cross-cutting/REQ-037-saved-content-durability.md)に従う。
- 追加ルール：画像作業領域と保存先の容量不足・アクセス拒否をモーダルで通知し、保存せず、別の場所へ自動切替しない。表示キャッシュ解放時の画像保持には[REQ-039](../../non-functional-requirements/cross-cutting/REQ-039-image-asset-retention.md)を適用する。
- 保存・排他共通ルール：[同一ファイル利用と保存再試行](REQ-032-file-lock-and-save-retry.md#同一ファイル利用と保存再試行の共通ルール)を適用する。
- 根拠・出典：[保存完了と再開の保証範囲](../../../product-demands/product-decisions/2026-10-14-save-completion-and-resumption-policy.md#決定内容)、[設定の独立保存とフォント差再開の反映判断](../../../product-demands/product-decisions/2026-10-06-project-settings-and-font-resumption.md#決定内容)、[同一ファイル利用と保存再試行の判断](../../../product-demands/product-decisions/2026-10-06-project-lock-and-save-retry.md#決定内容)、[画像とプロジェクトの利用上限の反映判断](../../../product-demands/product-decisions/2026-10-06-image-and-project-limits.md#決定内容)。参照要求の期待成果と、各記録の決定内容・適用範囲を具体化する。
- 設定共通ルール：[設定の保存・失敗・適用範囲](REQ-030-shared-settings.md#設定の共通ルール)に従う。
- 優先度・理由：必須。画像・配置・グループ・メモを保ち後日再開するという初期成果を、保存失敗時の内容保護と再試行の振る舞い・条件で満たすため。
- 合意状況：ドラフト（共通設定への統合・ボード分離の変更部分は再レビュー対象）
- 依存要件：[REQ-011](REQ-011-restore-saved-content.md#req-011保存内容の復元)、[REQ-015](REQ-015-save-status.md#req-015保存状態の識別)
- 未決事項：保存失敗後の振る舞い・復元保証範囲は具体化済み。設計担当は実装引継ぎ前にライブラリ・排他／再試行契約を確認し、検証担当は検証計画時に障害・異常終了の再現手順を固定し、受入実施前に本項・共通条件の成立を確認する。現在の合意状況は冒頭の既存項目を参照する。技術検証は後続へ引き継ぎ、未実施の試験を合格としない。

### 受入条件

| ケース | 前提 | 操作・事象 | 期待結果 |
| --- | --- | --- | --- |
| 異常 | 保存済み内容に変更を加え、保存失敗を再現できる | 保存を失敗させる | 直前保存内容と編集中内容が保たれ、未保存を確認できる |
| 異常 | 保存失敗後もアプリが動作している | 編集を続け、原因解消後に再試行する | 編集でき、再試行で内容を保存できる |
| 正常 | 復旧用保持が有効で旧保存がある | 設定保存と表示位置だけのボード保存を各々成功させる | ボード保存だけ直前のファイルが復旧用1世代となり、設定保存ではボードと復旧用は不変 |
| 異常 | 退避・復旧用から内容を開いた | 再保存を試みる | 元ファイルや開いた復旧用を上書きせず別名保存する。保存前の再度の異常終了でも唯一の正常内容が残る |
| 異常 | 作業領域または保存先へ書込み不可 | 取込または保存する | モーダルで理由を通知し、自動で保存先を変更しない。未保存内容・既存正常ファイルを保持する |
| 異常 | 本ファイル置換後の保存失敗 | 追加入力後に再試行し、中断内容が一致する | 中断分だけ成功基準に進め、追加入力を保持・未保存として後続保存する |
| 異常 | 外部変更・削除・記録不一致 | 再試行する | 元保存先を上書きせず編集を保持し別名保存できる。外部版の読込には未保存保護を使う |
| 異常 | 共通設定の保存／読込が失敗 | 設定変更または起動する | 保存失敗は即時6項目の適用値を保持し、次回適用2項目は旧成功値。入力・未保存・再試行を保持。読込失敗は通知して通常既定値。実作業先失敗では自動代替しない |

- 変更根拠：[共通設定とボード分離の判断](../../../product-demands/product-decisions/2026-10-17-common-settings-and-board-separation.md)。設定の範囲・保存先・適用時点はREQ-030を正本とし、変更範囲の詳細レビューと製品検証は未完了。
