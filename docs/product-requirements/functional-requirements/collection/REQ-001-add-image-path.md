# REQ-001：画像の追加経路

- 種類：機能
- 参照要求：[DEM-001](../../../product-demands/collection/DEM-001-collect-reference-images.md#dem-001比較したい参考画像を継続して蓄積する)
- 参照時点の要求：DEM-001「参考画像を取り込み継続して蓄積する」。参照要求はいずれも合意済み。
- 内容：ローカル画像をドラッグ＆ドロップまたはファイルダイアログでの単一・複数ファイル選択により、ブラウザ画像をドラッグ＆ドロップまたは画像コピー後のクリップボード貼り付けにより、単一ボードへ追加できる。
- 適用条件：利用者のWindows 11初期版での単一ボードの利用。
- 業務ルール・例外：対応ブラウザはChrome・Edgeとし、受入試験開始時点の安定版を対象とする。ログイン不要のページでブラウザ標準の画像コピー・ドラッグができる画像を取込対象とする。ブラウザからの画像URL入力は不要。ローカル画像の両取込経路には[REQ-002](REQ-002-static-image-formats.md#req-002静止画形式と複数フレームの扱い)の対応形式と[REQ-003](REQ-003-batch-import-errors.md#req-003複数取込と失敗通知)の失敗時の扱いを適用する。ファイルダイアログをキャンセルした場合、画像を追加せず、ボードの内容を変更しない。
- 追加ルール：取込経路にかかわらず[利用上限](../../non-functional-requirements/cross-cutting/REQ-029-image-and-project-limits.md#画像とプロジェクトの利用上限)を適用し、超過対象を理由付きで通知する。
- 優先度・理由：必須。参考画像を取り込み継続して蓄積するという初期成果を、今回回答された画像の追加経路の振る舞い・条件で満たすため。
- 根拠・出典：上記参照要求、[現行5要求への合意](../../../product-demands/product-decisions/2026-09-13-final-demand-agreement.md#決定内容)、今回の要件定義対話でのユーザーの回答（親エージェント経由の要約）。ファイルダイアログからの読込追加はユーザーの明示的な希望。単一・複数選択とキャンセル時の扱いはユーザーが実施を指示した更新計画による。 未決事項インタビューにおけるユーザーの回答：Chrome・Edgeの受入試験開始時点の安定版と、ログイン不要の通常のWeb画像を対象にする。
- 変更根拠：ユーザーの計画実行指示。意味・受入条件の変更によりドラフトとし、従前の合意を変更後本文への合意とはしない。
- 合意状況：ドラフト
- 依存要件：なし
- 未決事項：なし。検証で使用するChrome・Edgeの具体的なバージョン番号は、受入試験開始時に記録する。

### 受入条件

| ケース | 前提 | 操作・事象 | 期待結果 |
| --- | --- | --- | --- |
| 正常 | 対応形式のローカル画像がある | 画像をドラッグ＆ドロップする | ボードに追加され比較できる |
| 正常 | 対応形式の読取可能なローカル画像がある | ファイルダイアログで1枚または複数枚を選択して確定する | 選択した画像がすべてボードに追加される |
| 正常 | ファイルダイアログを開いている | 選択を確定せずキャンセルする | 画像は追加されず、ボードの内容は変わらない |
| 正常 | 上記対象ブラウザ・対象範囲の画像を表示している | 画像をドラッグする／画像をコピーして貼り付ける | 各経路で画像が追加される |
| 正常 | 受入試験開始時点のChrome・Edge安定版で、ログイン不要のページに標準の画像コピー・ドラッグが可能な画像を表示している | 各ブラウザで画像のドラッグと画像コピー後の貼り付けをそれぞれ行う | 各経路で画像を追加できる。使用したブラウザ名とバージョン番号を記録する |
| 異常 | 元画像の画素数・一辺・ファイル容量のいずれかが上限超過 | 各取込経路から追加する | 対象と理由が分かり、超過画像は追加されず既存内容を保持する |

## 文脈

画像処理・資源管理・読込制限の計画を反映。意味変更した要件は各項のとおりドラフトとし、従前の合意と区別する。

利用者が手持ち画像やブラウザ画像を単一ボードへ集める。別画像ライブラリは今回の対象外。

各要件は要求とユーザーの回答を具体化し、ユーザーが当時の本文・受入条件・優先度（全件必須）と提示した分類に明示的に合意した。現在の合意状況と根拠は各要件に記載する。条件付き合意の未決事項は後続工程へ引き継ぎ、実装完了・試験合格とは区別する。
