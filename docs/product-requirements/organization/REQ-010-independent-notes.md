# REQ-010：独立メモの編集と配置

- 種類：機能
- 参照要求：[DEM-003](../../product-demands/organization/DEM-003-organize-image-insights.md#dem-003画像の関係や気づきを自分なりに整理する)
- 参照時点の要求：DEM-003「配置・グループと独立メモで意図を整理する」。参照要求はいずれも合意済み。
- 内容：画像・グループへの所属なしでメモを作成・配置・編集・削除できる。幅は初期320、120～4,096ボード単位、文字サイズは初期16、12・14・16・18・24・32から選択、行高は文字サイズの1.5倍。本文と手動改行を保持して幅に折り返し、高さは全文に追従する。本文上限は10,000拡張書記素クラスタ、改行は1文字とする。
- 編集共通ルール：[編集履歴と重なり順](REQ-027-edit-history-and-stacking.md#編集履歴と重なり順の共通ルール)を適用する。
- 配置共通ルール：[配置・グリッド・スナップ](REQ-028-placement-grid-and-snapping.md#配置グリッドスナップの共通ルール)を適用する。
- 適用条件：利用者のWindows 11初期版での単一ボードの利用。
- 業務ルール・例外：画像やグループのコメントとしてのみ存在する扱いにはしない。独立メモは所属せず利用できることを意味し、任意のグループ所属を妨げない。所属・解除は[REQ-008](REQ-008-group-membership.md#req-008グループへの所属と解除)、一括移動は[REQ-009](REQ-009-group-movement.md#req-009グループの一括移動)、保存・復元は[REQ-011](../cross-cutting/REQ-011-restore-saved-content.md#req-011保存内容の復元)に従う。
- 追加ルール：メモの新規作成・編集にも[利用上限](../cross-cutting/REQ-029-image-and-project-limits.md#画像とプロジェクトの利用上限)を適用する。上限を超える変更は拒否し、既存内容を維持する。
- 入力・確定ルール：完了・取消は画面操作とし専用キーを設けず、Enterは改行。本文編集中は幅・文字サイズ変更を終了後へ回す。文字サイズ／幅変更と付随する高さ・必要枠拡大は同じボードUndo単位とする。各PC標準フォントを使用し、別PC再開時の調整は[REQ-011](../cross-cutting/REQ-011-restore-saved-content.md#req-011保存内容の復元)に従う。
- 編集期間・フォーカス：文章内Undoは同じ編集期間中の保存境界を越え、ボードUndoへ自動切替しない。メモ外のボード・要素クリックは本文確定→編集終了→クリック先操作の順。保存ボタン・別アプリ切替では編集を継続する。取消は直近確定本文へ戻す。保存失敗でも確定境界を維持する。
- IME・超過入力：変換中の外側クリックはボード操作を実行・予約せず、終了後の再操作を必要とする。変換中の値を保存・ボード履歴へ混入しない。超過貼付けは全体拒否・通知し本文・選択範囲・文章内履歴を保持。変換確定で超過なら今回の変換を拒否・通知し、変換開始前の本文・選択範囲へ戻す。結合文字・家族絵文字をクラスタ単位で数え、改行表現を1文字へ揃え、他のUnicode正規化で本文を変えない。計数の版・実現方式は設計担当が決定・検証する。
- 空メモ・取消：空本文も確定・保存できる。新規未確定の取消は作成取消で履歴なし。一度確定したメモは取消しても残し、直近確定本文へ戻す。保存失敗時も同じ境界を適用する。
- 優先度・理由：必須。配置・グループと独立メモで意図を整理するという初期成果を、今回回答された独立メモの編集と配置の振る舞い・条件で満たすため。
- 根拠・出典：上記参照要求、[現行5要求への合意](../../product-demands/product-decisions/2026-09-13-final-demand-agreement.md#決定内容)、今回の要件定義対話でのユーザーの回答（親エージェント経由の要約）。 未決事項インタビューにおけるユーザーの回答：メモは単独でも任意のグループ要素としても使える。文字数等の上限は設計・試作評価へスキップする。
- 変更根拠：ユーザーの計画実行指示。意味・受入条件の変更によりドラフトとし、従前の合意を変更後本文への合意とはしない。
- 今回の反映根拠：ユーザーのセッション決定と要件反映計画の実行指示。[編集・履歴・スナップの判断](../../product-demands/product-decisions/2026-10-06-board-editing-and-snap.md#決定内容)および[表示・寸法の判断](../../product-demands/product-decisions/2026-10-06-board-view-and-note-display.md#決定内容)の決定内容に基づく反映。決定済み振る舞いと変更後REQ全体の合意・製品試験を区別する。
- 合意状況：ドラフト
- 依存要件：なし
- 未決事項：本要件と共通ルールの振る舞い・数値境界は具体化済み。設計担当は実装引継ぎ前に本文・受入条件との一致をレビューし、検証担当は受入実施前に組合せ操作と異常処理の成立を確認する。解消条件は記載した期待結果の成立。設計・検証に残る入力方式・ライブラリ・実機確認を、利用者の未回答扱いに戻さない。変更後REQは合意レビュー待ち。

### 受入条件

| ケース | 前提 | 操作・事象 | 期待結果 |
| --- | --- | --- | --- |
| 正常 | ボードを開いている | メモを作成し、配置・文章を変更する | 画像・グループへの所属なしで変更した位置と文章を確認できる |
| 正常 | メモがある | メモを削除する | 対象メモが除かれる |
| 正常 | グループに所属したメモがある | メモ文章を編集し、グループから除外する | 編集内容と配置が維持され、未所属の独立メモとして引き続き利用できる |
| 異常 | ボード要素数が100,000または変更結果が容量上限超過 | メモを追加・編集する | 変更を拒否して理由を通知し、既存文章・配置を保持する |
| 正常 | 改行を含む長いメモがある | メモ幅を変更する | 手動改行を保持して折り返し、高さが全文に追従する。保存・再開で本文・位置・幅を復元する |
| 正常 | ASCII文字で長さを確認できる本文 | 9,999文字から10,000文字へ編集する | 上限以内の本文を保持できる |
| 異常 | 10,000文字の本文がある | 上限を超える本文を確定しようとする | 今回の超過入力を拒否・通知し、本文を切り捨てない。貼付けは全体拒否し本文・選択範囲を保持、IMEは変換開始前へ戻す |
| 正常 | 結合文字・家族絵文字・改行を含む本文 | 9,999から10,000クラスタへ入力する | 結合文字・家族絵文字は各クラスタ1、改行1で計数し上限一致を保持できる |
| 異常 | 選択範囲を置換しても10,000を超える貼付け | 貼付けする | 全体を拒否・通知し、本文・選択範囲・文章内履歴を保持する |
| 異常 | IME変換開始前の本文・選択範囲を保持している | 変換確定で10,000を超える | 今回の変換を拒否・通知し、開始前本文・選択範囲へ戻す |
| 正常 | IME変換中 | 外側のボード・要素をクリックし、その後変換を終える | 操作は実行も予約もしない。編集終了や遅れてのボード操作をせず、再操作で扱う |
| 正常 | A→ABを途中保存→ABCへ編集中 | 文章内UndoでAまで戻し、編集を取消する | 保存境界を越えて文章内だけでUndoでき、取消は直近確定ABへ戻る。ボードUndoへ切替しない |
| 正常 | 本文編集中 | 外側のボード・要素クリック／保存／別アプリ切替を行う | 外側クリックは確定終了後に対象操作。保存・別アプリ切替は編集継続。Enterは改行、完了・取消は画面操作 |
| 正常 | 空の新規メモ | 未確定取消／空確定後に取消・保存する | 未確定取消は作成なし・履歴なし。確定後は空メモを残し保存可能 |
| 異常 | 新規または既存メモの本文確定後に保存失敗 | 続けて入力し取消する | メモを残して直近確定本文へ戻し、失敗で確定境界を巻き戻さない |
| 正常 | メモの幅・文字サイズを変更できる | 幅120・4,096、文字12・14・16・18・24・32を選ぶ | 全文高・行高1.5倍を保ち、必要枠拡大と一括Undoできる。本文編集中は変更を終了後へ回す |
| 異常 | 幅範囲を超える操作 | 120未満／4,096超へ変更する | 最後の有効寸法を維持し上限を通知、解放で確定、取消で開始前へ戻す |
