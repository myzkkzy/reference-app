# 継続利用：横断要求

## 共通する背景

[構想](../product-ideas/reference-board.md)では、画像を継続蓄積し、画像と配置を端末内に保存したいという意向がある。今回、別PCへの持ち運びも初期に必要との回答を得た（[別PCへの持ち運びを初期対象とする判断](product-decisions/2026-09-11-initial-portability.md)）。端末内保存と持ち運びは両立させたい意向として扱い、同期などの方式は確定しない。

利用環境について本人はWindowsと回答し、クロスプラットフォーム対応を希望した。Windowsを初版対象とし、macOS・Linuxは将来対応とする（[初版と将来の対応OSの判断](product-decisions/2026-09-12-platform-scope.md)）。全関係者の利用OSが確認済みという意味ではない。共通の環境制約はDEM-004で管理する。

## DEM-004：蓄積内容を保ち後日再開する

- 対象者・状況：本人が参考画像の収集・比較・整理をいったん終え、後日続ける。
- 対象範囲・対象外：画像・配置・グループ・独立したメモを保持し後日再開することを扱う。本人は再開のために残す内容としてこの4点で十分と回答した。別PCでの継続は [DEM-005](#dem-005別pcでも蓄積内容を使い続ける) を参照する。
- 関連するテーマ：[参考画像の収集](collection.md)、[参考画像の探索・着想整理](comparison.md)。
- 課題：継続蓄積には過去の作業成果を利用し続ける必要がある。現状での消失や再作業の経験は未確認。
- 望む成果：これまでに蓄積・整理した内容を活かして後日の作業を再開できる。
- 理由・価値：継続して比較材料を増やし、整理にかけた時間を次の利用にも活かすため。
- 根拠・出典：[構想](../product-ideas/reference-board.md)の継続蓄積・端末内保存の意向、[後日再開と別PCへの持ち運び対象の判断](product-decisions/2026-09-12-resumption-content.md#決定内容)。 [現行5要求への合意](product-decisions/2026-09-13-final-demand-agreement.md#決定内容)。
- 優先度・理由：必須。保存して後日再開することは初期版に必須と本人が回答した（[収集と後日再開を初期必須とする判断](product-decisions/2026-09-12-initial-collection-resumption.md#決定内容)）。
- 成功指標：普段の利用で試し、支障なく続けられたかを振り返る。保存後も続きを進められることを実際に試し、本人が十分に役立つと判断できることを初期版の達成目安とする。数値目標は初期判断に必須としない。評価期間は試せる段階で決める（[初期版の達成目安と評価方法の判断](product-decisions/2026-09-13-initial-success-criteria.md#決定内容)）。有用性は未検証。制作物の品質・創造性向上は初期条件に含めない。
- 合意状況：合意済み
- 関連要求：[DEM-001](collection.md)、[DEM-002](comparison.md)、[DEM-003](organization.md)、[DEM-005](#dem-005別pcでも蓄積内容を使い続ける)。
- 未決事項・仮定：現状の困難。評価期間は試せる段階で判断する。保持対象の判断は保存方式・自動保存・履歴保持を指定するものではない。共通の対象OSはWindowsを初版、macOS・Linuxを将来対応とする指定（[対応OSの判断](product-decisions/2026-09-12-platform-scope.md)）。提供形態はポータブルアプリケーション（本人の説明ではインストール不要）を希望し（2026-09-12の本人回答を親エージェント経由で受領した要約）。Windows初版でインストール不要とすることは必須（[提供形態の判断](product-decisions/2026-09-12-initial-portable-application.md#決定内容)）。OSのバージョン、将来対応の時期、保存・復元、提供形態の具体化は未決で要件定義担当へ引き継ぐ。

## DEM-005：別PCでも蓄積内容を使い続ける

- 対象者・状況：本人がメインPCではなくサブPCで作業するときに利用する。本人は頻度は高くないと回答した（2026-09-12の本人回答を親エージェント経由で受領した要約）。
- 対象範囲・対象外：本人の別PCへの持ち運びと継続利用を扱い、画像・配置・グループ・独立したメモを引き継げれば十分とする。他の制作者への共有は今回の対象外（[DEM-006の廃止](#dem-006他の制作者とリファレンスを確認し考えや方向性をすり合わせる)）。持ち運び方法や同期の扱いは未決であり、要件定義への引継ぎ事項で管理する。
- 関連するテーマ：[参考画像の収集](collection.md)、[参考画像の探索・着想整理](comparison.md)。
- 課題：本人は別PCへの持ち運びを必要としており、同じPC内だけで利用が完結する範囲では期待を満たさない。サブPCで作業する場面を想定しており、頻度は高くない。
- 望む成果：これまでの蓄積内容を別PCでも活かし、収集・比較・整理を続けられる。
- 理由・価値：利用するPCが変わっても、それまでの材料と作業成果を利用し続けるため。
- 根拠・出典：[別PCへの持ち運びを初期対象とする判断](product-decisions/2026-09-11-initial-portability.md)、[後日再開と別PCへの持ち運び対象の判断](product-decisions/2026-09-12-resumption-content.md#決定内容)。[構想](../product-ideas/reference-board.md)のOSを限定せず使いたい意向も関連するが、異OS間の持ち運びの指定とは扱わない。 [現行5要求への合意](product-decisions/2026-09-13-final-demand-agreement.md#決定内容)。
- 優先度・理由：必須。本人が持ち運びを初期に必要と回答している。
- 成功指標：普段の利用で試し、支障なく続けられたかを振り返る。別PCへの移動後も続きを進められることを実際に試し、本人が十分に役立つと判断できることを初期版の達成目安とする。数値目標は初期判断に必須としない。評価期間は試せる段階で決める（[初期版の達成目安と評価方法の判断](product-decisions/2026-09-13-initial-success-criteria.md#決定内容)）。有用性は未検証。制作物の品質・創造性向上は初期条件に含めない。
- 合意状況：合意済み
- 関連要求：[DEM-004](#dem-004蓄積内容を保ち後日再開する)、[DEM-001](collection.md)、[DEM-002](comparison.md)、[DEM-003](organization.md)。
- 未決事項・仮定：サブPCの実際のOSなどの利用環境。評価期間は試せる段階で判断する。持ち運び方法・同期の扱いは未決。対応OS・提供形態の共通事項は [DEM-004](#dem-004蓄積内容を保ち後日再開する) を参照する。

## DEM-006：他の制作者とリファレンスを確認し考えや方向性をすり合わせる

- 合意状況：廃止
- 対象者・状況：旧要求では本人と他の制作者によるリファレンスの確認を想定していた。
- 対象範囲・対象外：今回のプロダクトでは不要との本人判断により、共有・編集・返却を含む要求全体を対象外とする。
- 課題・望む成果：旧要求の他者との考えや方向性のすり合わせは現行の期待成果に含めない。
- 理由・根拠：[他の制作者との共有要求を廃止する判断](product-decisions/2026-09-13-retire-collaborator-sharing.md#決定内容)。旧意向は[初期共有の判断](product-decisions/2026-09-12-initial-project-sharing.md)に履歴として残す。
- 優先度・理由：未決（廃止により現行の優先度評価対象外）。旧「必須」は適用しない。
- 成功指標：現行評価の対象外。[初期版の達成目安](product-decisions/2026-09-13-initial-success-criteria.md)のうち本要求に対応する成果は廃止判断により適用しない。
- 関連要求：[DEM-003](organization.md)の本人の整理・想起、[DEM-005](#dem-005別pcでも蓄積内容を使い続ける)の本人の別PC利用は維持する。
- 未決事項・仮定：本要求の要件具体化は引き継がない。将来候補への振替や恒久的な機能禁止は判断していない。IDは廃止済みとして保持し再利用しない。

## 未確認事項の引継ぎ方針

現在の対象はDEM-001〜005。[DEM-006の廃止判断](product-decisions/2026-09-13-retire-collaborator-sharing.md#決定内容)により、過去の評価方針・達成目安・引継ぎ方針に含まれる共有関連部分は現行対象に適用しない。

2026-09-13、本人は次の扱いに合意した（親エージェント経由で受領した会話回答の要約）。画像形式・操作・保存・配布方法・対応OSのバージョンなどは要件定義で具体化する。実際の有用性と評価期間は試用時に確認する。困りごとの頻度や負担など、本文で未確認とした補足情報は未確認のまま引き継ぐ。既に確認した事実、初期範囲と期待成果を維持する。この引継ぎ方針は[現行5要求への最終合意](product-decisions/2026-09-13-final-demand-agreement.md#決定内容)後も維持し、未確認事項を確定済みとは扱わない。
