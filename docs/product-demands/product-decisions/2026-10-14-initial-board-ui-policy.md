# 初期版の表示・キー操作・画像配置の方針

- 判断日：不明
- 記録日：2026-10-14

## 背景

既存設計に記載されたプロダクト上の表示・操作方針を整理する。設計文書を整理元とする記録であり、上流要件の確定根拠へ転用しない。

## 決定内容

初版の表示はダーク固定とする。明暗テーマ切替・OSテーマ連動・プロジェクトのテーマ保存を追加しない。具体的な配色は設計案として扱う。

初版のキー操作・中ボタンパンは次の範囲とする。

| 入力 | 操作 | 適用する入力先・状態 |
| --- | --- | --- |
| Ctrl+S | 手動保存 | 既存の保存対象確定と保存ゲートを通す。メモ入力を継続し、IME変換部分を保存に含めない |
| Ctrl+O | 保存内容を開く | 既存の切替・未保存確認ゲートを通す。IME変換中は切替を始めず、変換完了後の再操作を待つ |
| Ctrl+Z | Undo | ボードの確定履歴。文章入力中は文章内Undoを優先 |
| Ctrl+Y／Ctrl+Shift+Z | Redo | ボードの確定履歴。文章入力中は文章内Redoを優先 |
| Shift+クリック | 追加選択 | ボード要素。textarea内の選択操作へ流用しない |
| Delete | 選択画像を削除 | ボードにフォーカスがあり配置操作中でない場合。文章入力・他の入力欄では文字編集を優先 |
| Escape | 配置操作を開始前へ戻す | 画像・グループ・メモの配置操作中。文章入力／IMEではボード取消へ転送しない |
| 中ボタン＋ドラッグ | パン | ボード領域。選択・要素移動へ転送せず、WebViewの既定オートスクロールを抑止 |
| ホイール | カーソル中心ズーム | ボード領域。textarea・スクロール可能なダイアログではその入力先のスクロールを優先 |

同時ジェスチャーは一つに限定し、配置操作中に別のパンを開始しない。ボードショートカットをIME・textarea・他の入力欄・確認ダイアログへ無条件に適用しない。文章入力中のEnterは改行、Escapeを編集取消に割り当てない。Undo／Redoの対象範囲はREQ-027・DES-002を維持し、画像取込Undoを新機能として追加しない。

要件担当へ：REQ-004・006～010・014・027の本文・受入条件へ入力先と取消の境界を照合する。正常案は各割当てが対象操作を実行し、保存中もパン・ズームを継続できること。異常案はIME・文章入力・確認中のキーで誤削除・誤取消・無条件切替が起きないこと。フォーカス・実機操作感はDES-013の成立確認へ引き継ぐ。

ブラウザのドラッグで画像URLだけを得た場合は自動取得する。初期画像は長辺320、グリッド配置、既存要素を避ける方針とする。API・補助ライブラリ・配置間隔は設計案であり、本記録で新たに確定しない。
