# DEM-006：他の制作者とリファレンスを確認し考えや方向性をすり合わせる

- 合意状況：廃止
- 対象者・状況：旧要求では利用者と他の制作者によるリファレンスの確認を想定していた。
- 対象範囲・対象外：今回のプロダクトでは不要とのユーザーの判断により、共有・編集・返却を含む要求全体を対象外とする。
- 課題・望む成果：旧要求の他者との考えや方向性のすり合わせは現行の期待成果に含めない。
- 理由・根拠：[他の制作者との共有要求を廃止する判断](../product-decisions/2026-09-13-retire-collaborator-sharing.md#決定内容)。旧意向は[初期共有の判断](../product-decisions/2026-09-12-initial-project-sharing.md)に履歴として残す。
- 優先度・理由：未決（廃止により現行の優先度評価対象外）。旧「必須」は適用しない。
- 成功指標：現行評価の対象外。[初期版の達成目安](../product-decisions/2026-09-13-initial-success-criteria.md)のうち本要求に対応する成果は廃止判断により適用しない。
- 関連要求：[DEM-003](../organization/DEM-003-organize-image-insights.md)の利用者の整理・想起、[DEM-005](DEM-005-continue-on-another-pc.md#dem-005別pcでも蓄積内容を使い続ける)の利用者の別PC利用は維持する。
- 未決事項・仮定：本要求の要件具体化は引き継がない。将来候補への振替や恒久的な機能禁止は判断していない。IDは廃止済みとして保持し再利用しない。
