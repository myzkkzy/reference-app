# DEM-004：蓄積内容を保ち後日再開する

- 対象者・状況：利用者が参考画像の収集・比較・整理をいったん終え、後日続ける。
- 対象範囲・対象外：画像・配置・グループ・独立したメモを保持し後日再開することを扱う。ユーザーは再開のために残す内容としてこの4点で十分と回答した。別PCでの継続は [DEM-005](DEM-005-continue-on-another-pc.md#dem-005別pcでも蓄積内容を使い続ける) を参照する。
- 関連するテーマ：[参考画像の収集](../collection/index.md)、[参考画像の探索・着想整理](../comparison/index.md)。
- 課題：継続蓄積には過去の作業成果を利用し続ける必要がある。現状での消失や再作業の経験は未確認。
- 望む成果：これまでに蓄積・整理した内容を活かして後日の作業を再開できる。
- 理由・価値：継続して比較材料を増やし、整理にかけた時間を次の利用にも活かすため。
- 根拠・出典：[構想](../../product-ideas/reference-board/IDEA-001-reference-board.md)の継続蓄積・端末内保存の意向、[後日再開と別PCへの持ち運び対象の判断](../product-decisions/2026-09-12-resumption-content.md#決定内容)。 [現行5要求への合意](../product-decisions/2026-09-13-final-demand-agreement.md#決定内容)。
- 優先度・理由：必須。保存して後日再開することは初期版に必須とユーザーが回答した（[収集と後日再開を初期必須とする判断](../product-decisions/2026-09-12-initial-collection-resumption.md#決定内容)）。
- 成功指標：普段の利用で試し、支障なく続けられたかを振り返る。保存後も続きを進められることを実際に試し、ユーザーが十分に役立つと判断できることを初期版の達成目安とする。数値目標は初期判断に必須としない。評価期間は試せる段階で決める（[初期版の達成目安と評価方法の判断](../product-decisions/2026-09-13-initial-success-criteria.md#決定内容)）。有用性は未検証。制作物の品質・創造性向上は初期条件に含めない。
- 合意状況：合意済み
- 関連要求：[DEM-001](../collection/DEM-001-collect-reference-images.md)、[DEM-002](../comparison/DEM-002-compare-image-overviews.md)、[DEM-003](../organization/DEM-003-organize-image-insights.md)、[DEM-005](DEM-005-continue-on-another-pc.md#dem-005別pcでも蓄積内容を使い続ける)。
- 未決事項・仮定：現状の困難。評価期間は試せる段階で判断する。保持対象の判断は保存方式・自動保存・履歴保持を指定するものではない。共通の対象OSはWindowsを初版、macOS・Linuxを将来対応とする指定（[対応OSの判断](../product-decisions/2026-09-12-platform-scope.md)）。提供形態はポータブルアプリケーション（ユーザーの説明ではインストール不要）を希望している（ユーザーの回答を親エージェント経由で受領した要約）。Windows初版でインストール不要とすることは必須（[提供形態の判断](../product-decisions/2026-09-12-initial-portable-application.md#決定内容)）。OSのバージョン、将来対応の時期、保存・復元、提供形態の具体化は未決で要件定義担当へ引き継ぐ。

## 共通する背景

[構想](../../product-ideas/reference-board/IDEA-001-reference-board.md)では、画像を継続蓄積し、画像と配置を端末内に保存したいという意向がある。今回、別PCへの持ち運びも初期に必要との回答を得た（[別PCへの持ち運びを初期対象とする判断](../product-decisions/2026-09-11-initial-portability.md)）。端末内保存と持ち運びは両立させたい意向として扱い、同期などの方式は確定しない。

利用環境についてユーザーはWindowsと回答し、クロスプラットフォーム対応を希望した。Windowsを初版対象とし、macOS・Linuxは将来対応とする（[初版と将来の対応OSの判断](../product-decisions/2026-09-12-platform-scope.md)）。全関係者の利用OSが確認済みという意味ではない。共通の環境制約はDEM-004で管理する。

## 未確認事項の引継ぎ方針

現在の対象はDEM-001〜005。[DEM-006の廃止判断](DEM-006-share-reference-insights.md)により、過去の評価方針・達成目安・引継ぎ方針に含まれる共有関連部分は現行対象に適用しない。

ユーザーは次の扱いに合意した（親エージェント経由で受領した会話回答の要約）。画像形式・操作・保存・配布方法・対応OSのバージョンなどは要件定義で具体化する。実際の有用性と評価期間は試用時に確認する。困りごとの頻度や負担など、本文で未確認とした補足情報は未確認のまま引き継ぐ。既に確認した事実、初期範囲と期待成果を維持する。この引継ぎ方針は[現行5要求への最終合意](../product-decisions/2026-09-13-final-demand-agreement.md#決定内容)後も維持し、未確認事項を確定済みとは扱わない。
