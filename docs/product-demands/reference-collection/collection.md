# 参考画像の収集：要求

## 背景・利用状況

[構想](../../product-ideas/reference-board.md)では、手持ち画像とブラウザで見つけた画像を継続して集める意向がある。現状の代替手段はフォルダー・画像ビューアとペイントアプリのキャンバス（[初期評価の範囲](../product-decisions/2026-09-11-initial-evaluation.md)）。手持ち画像やブラウザの画像を参考用キャンバスへ集める際の困りごとを尋ねたところ、本人は現状で特に困っていないと回答した。これは2026-09-12の本人の会話回答を親エージェント経由で受領した要約であり、観察・実測ではない。

## DEM-001：比較したい参考画像を継続して蓄積する

- 対象者・状況：本人が手持ち・ブラウザの画像を比較材料として集め続ける。
- 対象範囲・対象外：本人がPCで参考画像を継続収集することを扱い、制作分野・収集用途は限定しない。別画像ライブラリは構想で未選択のため今回の対象外。収集後の比較・整理と継続利用は関連要求を参照する。
- 課題：比較に使いたい画像を継続して蓄積する必要がある。現在の収集方法について本人は特に困っていないと回答している。
- 望む成果：必要な参考画像を取り集め、後の比較に使える材料を継続して増やせる。
- 理由・価値：俯瞰・比較のための材料を手元に蓄積することが、利用の前提となる。
- 根拠・出典：[構想](../../product-ideas/reference-board.md)の本人意向。現状の手段は[初期評価の範囲](../product-decisions/2026-09-11-initial-evaluation.md)。現在の収集で特に困っていないという申告は[背景・利用状況](#背景利用状況)の2026-09-12の本人回答の要約。 [現行5要求への合意](../product-decisions/2026-09-13-final-demand-agreement.md#決定内容)。
- 優先度・理由：必須。画像を取り込んで蓄積することは初期版に必須と本人が回答した（[収集と後日再開を初期必須とする判断](../product-decisions/2026-09-12-initial-collection-resumption.md#決定内容)）。
- 成功指標：普段の利用で試し、支障なく続けられたかを振り返る。画像を集め続けられることを実際に試し、本人が十分に役立つと判断できることを初期版の達成目安とする。数値目標は初期判断に必須としない。評価期間は試せる段階で決める（[初期版の達成目安と評価方法の判断](../product-decisions/2026-09-13-initial-success-criteria.md#決定内容)）。有用性は未検証。制作物の品質・創造性向上は初期条件に含めない。
- 合意状況：合意済み
- 関連要求：[DEM-002](../reference-exploration/comparison.md)、[DEM-004・DEM-005](../cross-cutting.md)。
- 未決事項・仮定：評価期間は試せる段階で判断する。収集時間の短縮を合意済み目標にはしない。取込画像の範囲は要件定義担当へ引き継ぐ。他の利用者への有用性は未確認。収集と探索の2境界で整理する。比較の困難を収集の困難と同一視しない。
