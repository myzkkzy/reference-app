# 参考画像の収集：要求

## 背景・利用状況

[構想](../../product-ideas/reference-board.md)では、手持ち画像とブラウザで見つけた画像を継続して集める意向がある。現状の代替手段はフォルダー・画像ビューアとペイントアプリのキャンバス（[初期評価の範囲](../product-decisions/2026-09-11-initial-evaluation.md)）。収集時の具体的な困りごとは未確認。

## DEM-001：比較したい参考画像を継続して蓄積する

- 対象者・状況：本人が手持ち・ブラウザの画像を比較材料として集め続ける。
- 対象範囲・対象外：本人がPCで参考画像を継続収集することを扱い、制作分野・収集用途は限定しない。別画像ライブラリは構想で未選択のため今回の対象外。収集後の比較・整理と継続利用は関連要求を参照する。
- 課題：比較に使いたい画像を継続して蓄積する必要がある。現在の収集方法の不足や負担の程度は未確認。
- 望む成果：必要な参考画像を取り集め、後の比較に使える材料を継続して増やせる。
- 理由・価値：俯瞰・比較のための材料を手元に蓄積することが、利用の前提となる。
- 根拠・出典：[構想](../../product-ideas/reference-board.md)の本人意向。現状の手段は[初期評価の範囲](../product-decisions/2026-09-11-initial-evaluation.md)。
- 優先度・理由：重要（提案）。最優先の比較体験を支えるが、この要求の優先度への明示的合意は未取得。
- 成功指標：比較に使いたい画像を収集し続けられたかを本人の利用事例で評価する案。現状値・目標値・測定期間・具体的方法は未決。
- 合意状況：ドラフト
- 関連要求：[DEM-002](../reference-exploration/comparison.md)、[DEM-004・DEM-005](../cross-cutting.md)。
- 未決事項・仮定：現状の収集の困難、収集成果の評価方法、優先度。収集時間の短縮を合意済み目標にはしない。取込画像の範囲は要件定義担当へ引き継ぐ。他の利用者への有用性は未確認。収集と探索の2境界で整理する。比較の困難を収集の困難と同一視しない。
