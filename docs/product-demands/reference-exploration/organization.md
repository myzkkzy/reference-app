# 着想の整理：要求

## 背景・利用状況

本人は配置やグループ分けを楽しみながら考える作業として手間をかけたいと希望する（[構想](../../product-ideas/reference-board.md)）。グループ・文章コメントは初期に必要との回答がある（[グループ・文章コメントを初期対象とする判断](../product-decisions/2026-09-11-initial-organization.md)）。それらが整理を助ける効果は未検証。

## DEM-003：画像の関係や気づきを自分なりに整理する

- 対象者・状況：本人が参考画像を眺め、配置やまとまりについて考え、気づきを整理する。
- 対象範囲・対象外：本人による配置・グループ・文章コメントを用いた整理を扱う。画像の部分注釈・矢印は不要との意向により今回の対象外。自動整列してから動かす方式は今回未選択であり、自動整列を将来にわたり禁止する判断とは扱わない。
- 課題：眺めるだけでなく、自分なりの画像の関係や気づきを整理したい。現在の整理手段にどの程度の不足があるかは未確認。
- 望む成果：考える過程を楽しみながら、画像同士の関係や気づきを自分なりに整理できる。
- 理由・価値：配置・グループ分け自体を考える作業として重視している。整理時間の短縮は目標にしない。
- 根拠・出典：[構想](../../product-ideas/reference-board.md)の本人意向、[グループ・文章コメントを初期対象とする判断](../product-decisions/2026-09-11-initial-organization.md)。整理を助ける効果は構想の未検証仮説。
- 優先度・理由：必須。グループ・文章コメントは初期に必要という本人回答に基づく。
- 成功指標：本人が画像の関係や気づきを整理できたと感じるか、具体的な利用事例で評価する案。現状値・目標値・測定期間・具体的方法は未決。制作への効果は初期指標に含めない。
- 合意状況：ドラフト
- 関連要求：[DEM-002](comparison.md)、[DEM-004・DEM-005](../cross-cutting.md)。
- 未決事項・仮定：整理への有用性の評価方法と目標。現在の整理上の困難。機能の希望から成果が実証されたとは扱わない。自由配置・グループ・文章コメントが整理を助けることは未検証仮説。比較との評価範囲の関係は [DEM-002](comparison.md) を参照する。
