# 俯瞰と比較：要求

## 背景・利用状況

本人はフォルダー・画像ビューアに加えてペイントアプリのキャンバスに画像を並べるが、ツールバー・パネルが場所を取り、一度に見渡せる画像が少ないと回答した（[初期評価の範囲](../product-decisions/2026-09-11-initial-evaluation.md)）。実画面の観察・比較数の実測は未実施。

## DEM-002：多くの画像を見渡し全体と細部を比較する

- 対象者・状況：本人が蓄積した多数の参考画像をPCで眺め、気になる画像のまとまりや細部を比較する。
- 対象範囲・対象外：単一ボードでの俯瞰と比較を扱う。複数ボードは構想で未選択のため今回の対象外。初期評価は見渡し・比較の改善までとし、制作効果、市場・収益評価は対象外。市場・収益評価は本人向け有用性の判断に必須ではない。
- 課題：現在のキャンバスでも画像以外の表示が場所を取り、一度に見渡せる画像が少ない。
- 望む成果：多くの画像を見渡し、全体と細部を行き来しながら、現在より比較しやすいと本人が感じられる。
- 理由・価値：見渡せる範囲の狭さを解消することが本人の最優先。制作で試したい表現・構成を見つけることは長期の期待であり、初期評価の条件にしない。
- 根拠・出典：[構想](../../product-ideas/reference-board.md)、[初期評価の範囲](../product-decisions/2026-09-11-initial-evaluation.md)。初期成果の範囲は今回の回答を優先する。
- 優先度・理由：必須。本人が最優先とする見渡し・比較の改善を直接扱う。
- 成功指標：一度に比較できる画像の広がり、および全体と細部を比較する際の本人満足度を評価する案。同じPC・画面・画像群で現在の手段と比較する方法を提案する。現状値・目標値・測定期間・画像群や評価尺度の具体化は未決。
- 合意状況：ドラフト
- 関連要求：[DEM-001](../reference-collection/collection.md)、[DEM-003](organization.md)、[DEM-004・DEM-005](../cross-cutting.md)。
- 未決事項・仮定：見やすさと快適さの具体的な評価基準・方法・目標。制作への効果は未検証で、後の評価に委ねる。複数画像の比較が制作の発見につながることは未検証仮説。外部調査は未実施であり、市場・競合について確認済み事実はない。比較と整理の有用性は別々に評価する案。
