# 文書索引の更新

共通原則と権限は[スキルの入口](../SKILL.md)に従う。

## 入力と出力

- 入力：対象文書群、索引の範囲・列、管理元、リンク方式、適用規則。
- 出力：更新した一覧と参照、不足・重複の指摘。

## 手順

- 実在する文書・ID・本文見出しを調べ、索引の対象範囲を確認する。
- 本文へ直接到達できる参照と、一覧用の短い説明を記載する。
- 詳細、根拠、未決事項を索引へ重複転記しない。
- 対応表や候補の状態など、索引が正本となる項目は適用規則に従う。
- 存在しない関連文書へのリンクを追加しない。
- テンプレートの列だけを理由に、未実施作業を完了扱いにしない。
