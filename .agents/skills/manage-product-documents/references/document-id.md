# 文書IDの採番

共通原則と権限は[スキルの入口](../SKILL.md)に従う。

## 入力と出力

- 入力：採番対象、ID形式・範囲、既存・廃止文書、保存先、関連ID。
- 出力：対象本文へ反映した新規ID、または保存を伴わない暫定候補。

## 手順

- 採番の対象単位と全体の名前空間を確認する。アイデアを含め、接頭辞・連番範囲・採番対象は適用規則から取得する。分類をまたぐ連番の場合、他分類の既存・廃止IDも確認する。
- 既存・廃止済みIDと重複しない番号を選ぶ。固定の接頭辞を仮定しない。
- 編集・分類変更・移動では既存IDを維持し、廃止IDを再利用しない。IDと英語の内容名を組み合わせたファイルを使う場合はファイル名先頭のIDと本文IDの一致、適用規則に沿った内容名も確認する。
- 分割では移動する既存IDを維持し、追加する文書へ全種別・領域を通じた未使用IDを採番する。新旧関係・抽出範囲・正本を双方の本文へ記録し、適用規則に従って根拠・未決を引き継ぐ。採番を合意と扱わず、架空の上流IDを作らない。統合も新旧関係を残す。
- 保存直前に重複を再確認する。競合時は未使用の番号を選び直す。
- ID予約の台帳は新設しない。保存しない候補は予約済みと表現しない。
- 採番だけの依頼では本文の内容・状態・索引を別途変更しない。

## 確認例

- 入力：DOC-009が廃止済みで、保存前にDOC-010が追加された。
- 期待：DOC-009を再利用せず、保存直前の再確認でDOC-010との競合も回避する。
