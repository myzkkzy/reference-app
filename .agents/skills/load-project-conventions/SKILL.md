# 適用規則の確認

## 入力と出力

- 入力：対象ルート、依頼、既存の設定・規則への参照。
- 出力：適用する規則、その出典、未決事項、許可された作業範囲。

## 適用範囲

依頼と呼び出し元の権限を守り、指定された操作だけを行う。
適用規則は入力または既存設定から確認し、重要な不足だけ質問する。
保存先・ID体系・担当名を固定せず、明示された規則と既存成果物に合わせる。
独立した別操作が必要なら結果を引き継ぐ。別スキルの参照だけで作業を拡張しない。

## 手順

- 明示されたプロジェクトと規則を先に確認する。
- 規則の指定がなければ対象ルートの設定と既存成果物を調べる。
- 保存先、ID、状態、正本、担当権限、テンプレートの選択を整理する。
- 文書形式の指定がある場合は対象範囲・形式スキル・追加条件を確認し、後続へ渡す。指定のないプロジェクトへ形式を強制しない。
- 不足する重要事項だけ質問する。既存の指定を確認し直さない。
- 同梱した他プロジェクトの規則を暗黙に適用しない。
- 規則の確認によって権限を付与したり、後続工程を開始したりしない。

## 参照資料

- reference-app の規則を明示された場合：[プロジェクト規則](references/reference-app/index.md)。

## 確認例

- 入力：別プロジェクトでスキルだけを利用する。
- 期待：同梱のreference-app規則を自動適用せず、対象の設定を確認する。
