# 未決事項への質問

## 入力と出力

- 入力：確認したい事項、既知の情報、回答済みの質問、対話の仲介者。
- 出力：質問、取得した回答、根拠、未回答事項。

## 適用範囲

依頼と呼び出し元の権限を守り、指定された操作だけを行う。
適用規則は入力または既存設定から確認し、重要な不足だけ質問する。
保存先・ID体系・担当名を固定せず、明示された規則と既存成果物に合わせる。
独立した別操作が必要なら結果を引き継ぐ。別スキルの参照だけで作業を拡張しない。

## 手順

- 既存資料で解決できる質問を除き、影響の大きい未決事項を選ぶ。
- 一度に1〜3問を示す。判断が必要なら選択肢と推奨理由を添える。
- 分からないという回答には具体例や仮案を示し、同意を誘導しない。
- 未回答の質問を繰り返さず、回答と推測を分ける。
- 親が対話を仲介する場合は質問を親へ返し、取得した回答を受け取る。
- 個別の回答だけで文書全体への合意を推定しない。

## 確認例

- 入力：既存回答と未回答の質問がある。
- 期待：既知の内容と未回答の同じ質問を繰り返さず、重要な不足を整理する。
