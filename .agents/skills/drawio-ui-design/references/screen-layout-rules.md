# 画面構成図（低忠実度ワイヤーフレーム）

- 画面枠・ボタン・入力欄・選択肢などは`Mockup ***`の該当プリセットを優先する。実在する定義と必要なスタイルは[プリセット選択](mockup-presets.md)で確認する。該当表現のないアプリ固有の部品・状態だけをGeneralで補い、複合部品は必要に応じてグループ化する。
- 白・黒・グレーの低忠実度で画面やダイアログの外枠を描く。表示領域、ボタン、入力欄、選択肢、画像の仮枠、状態表示・通知を、利用者が見る位置と大まかな大きさで示す。細かな実装コンポーネントや配色を決めない。
- ボードの選択状態では枠と拡縮・回転ハンドル、操作中ではプレビューを実際の配置で示す。既定・処理中・失敗は必要に応じて部分ワイヤーフレームに分け、変化する部品が分かるようにする。
- 画面に出ない設計上の説明や出典は画面枠の外の注記に置く。注記が操作部品や他の注記に重ならないようにする。意図した包含やモーダルの重なりは区別して描く。
- 確定していない配置・文言・操作手段は「案」「未決」と図中に記す。実測寸法やピクセル値を根拠なく確定しない。
- 本文の画面責務、操作・通知、データ設計と用語を揃える。要件の振る舞いを図だけで追加・変更しない。
